# Reference Score

## Summary
The reference score rates the article's reference layer: sources present, formatted, alive, and matched to the claims they support.

## Details
- It combines the verifiability signals with source health — a page with great prose and dead references scores low here.
- The reference score is the most automatable evidence metric after the link score.
- For mykb, the reference score is computed from source-monitoring data and citation checks.
