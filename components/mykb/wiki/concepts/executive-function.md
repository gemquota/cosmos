# Executive Function

## Summary
Executive function is the set of high-level cognitive controls — planning, working memory management, inhibition, and task switching — that organize lower-level behavior. It matters because an agent without it reacts; with it, it executes strategy. In agent terms it maps to the orchestrator or planner role.

## Details
- Core abilities: goal maintenance, prioritization, stopping a wrong course, switching tasks.
- Failure modes: perseveration (stuck on one approach) and goal neglect.
- RSIS3 relevance: the executive planner and L3 goal direction are executive functions.
- Open questions: how to measure executive control quality in agents.
- Executive function is the set of high-level cognitive processes that control and coordinate other mental activities: planning, working memory, inhibition, and task switching.
- It is what lets an agent hold a goal, ignore distractions, sequence steps, and adapt when the plan meets reality.
- Executive function is fragile under load: stress, fatigue, and overload degrade inhibition and planning first.
- In artificial agents, executive function maps to the planning and self-monitoring layers that decide what to do next and whether it worked.
- **Worked example / comparison** — Worked example — an agent running a curation pass exercises executive function by keeping the batch goal active, resisting scope creep, and switching between review tasks without losing the plan.
- For mykb, executive function anchors the cognition cluster that RSIS3's planner draws on.
