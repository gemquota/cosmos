# Executive Function

## Summary
Executive function is the set of high-level cognitive controls — planning, working memory management, inhibition, and task switching — that organize lower-level behavior. It matters because an agent without it reacts; with it, it executes strategy. In agent terms it maps to the orchestrator or planner role.

## Details
- Core abilities: goal maintenance, prioritization, stopping a wrong course, switching tasks.
- Failure modes: perseveration (stuck on one approach) and goal neglect.
- RSIS3 relevance: the executive planner and L3 goal direction are executive functions.
- Open questions: how to measure executive control quality in agents.
