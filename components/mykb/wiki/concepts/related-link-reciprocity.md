# Related-Link Reciprocity

## Summary
Related-link reciprocity expects that when two articles are genuinely mutually relevant, each links to the other in its Related block.

## Details
- Checking reciprocity surfaces asymmetry: A links to B but B never mentions A, which usually means B is missing a link or A is forcing one.
- Reciprocity is a review heuristic, not a hard rule — a link from a broad overview to a niche detail can stay one-way.
- For mykb, reciprocity checks are part of the global link check's reporting layer.
