# Confounder Learning

## Summary
Confounder learning is a model treating a common cause as the predictive feature, e.g., predicting illness from clinic logos.

## Details
- Confounder learning is a model treating a common cause as the predictive feature, e.g., predicting illness from clinic logos.
- Confounded models fail when the confound changes.
- Causal modeling and invariance tests detect and correct it.
- RSIS3 relevance: graph statistics can confound topic and template effects.
