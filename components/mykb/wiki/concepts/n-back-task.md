# N-Back Task

## Summary

N-Back Task — Working-memory task: respond when the current stimulus matches one n positions back.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Requires continuous updating and maintenance of the stimulus stream.
- Used to measure working-memory capacity and train it (transfer is debated).
- Dual n-back variants add modality pairs.
- Standard in cognitive neuroscience of working memory.
