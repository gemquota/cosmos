# Archival Criteria

## Summary
Archival criteria define the transition from active wiki content to preserved-but-inactive storage: topic superseded, permanently stale, or merged into a broader article.

## Details
- Archival preserves the record — the file moves rather than disappears, keeping provenance and history for future reference.
- The criteria should be conservative: archiving is cheaper to delay than to undo, because readers lose the article's discoverability immediately.
- For mykb, archival criteria pair with deletion criteria: archive when the content still has reference value, delete only when it never did.
