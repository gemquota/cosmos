# Edit Warring

## Summary
Edit warring is repeatedly reverting another editor's changes to win control of an article — the same edit going back and forth.

## Details
- It is harmful even when the 'correct' side wins, because it burns goodwill and produces unstable content.
- The remedy is process, not force: stop editing, discuss, and route through dispute resolution; the three-revert rule sets the boundary.
- For mykb, edit warring on an article triggers protection and moves the dispute to the consensus process.
