# Weighting Articles

## Summary
Weighting articles assigns each article a weight in wiki-level metrics — by age, traffic, centrality, or quality — so aggregate numbers reflect what matters.

## Details
- Unweighted counts (total stubs, total links) are easy to game and easy to misread; weighting adds judgment.
- Weighting is a policy choice that must be recorded, because the same metric with different weights tells different stories.
- For mykb, weighting decisions live with the scoring rubric and are reviewed when the dashboard is reworked.
