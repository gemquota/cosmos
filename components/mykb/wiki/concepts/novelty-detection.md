# Novelty Detection

## Summary

Novelty Detection — Identifying inputs that differ from prior experience.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Novelty signals allocate attention and motivate exploration.
- Computational novelty detectors flag outliers in learned distributions.
- Imbalances: too sensitive → distraction; too lax → missed changes.
- Drives curiosity-driven learning and system monitoring.
