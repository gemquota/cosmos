# Todo Lists

## Summary
Todo lists are the lightweight side of task management: checklists of pending work that live with the person or sprint doing them.

## Details
- They work when they are short, current, and tied to an owner; a stale todo list is a liability.
- Todo lists differ from task lists in formality — todos are for the worker, tasks are for the system.
- For mykb, todo lists feed edit sprints and are consolidated into task lists when work crosses sessions.
