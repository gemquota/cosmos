# Top-Down Processing

## Summary

Top-Down Processing — Perception and cognition shaped by expectations, knowledge, and context.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Top-down signals fill in ambiguous input using priors and schemas.
- Explains why context disambiguates words, scenes, and faces.
- Can generate errors: expectations override weak bottom-up evidence.
- Complement of bottom-up processing; perception uses both.
