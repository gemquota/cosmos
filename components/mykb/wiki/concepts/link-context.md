# Link Context

## Summary
Link context is the sentence around a link that tells the reader why the target matters — the difference between a bare link and a link that explains why the target matters.

## Details
- Contextual links teach the reader the relationship; bare links only offer a detour.
- Link context is a writing quality that linters approximate and reviewers judge.
- For mykb, link context is part of the link-score and is a focus of review-sprints.
