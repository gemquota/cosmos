# Divided Attention

## Summary

Divided Attention — Processing multiple tasks or streams simultaneously.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Dual-task costs reveal capacity limits; some combinations automate with practice.
- Task similarity and resource type determine interference.
- Real multitasking is usually rapid task switching.
- Explains cognitive-offloading and attention-management practices.
