# Editor Guide

## Summary
The editor guide is the onboarding document that tells a new editor how the wiki works: the format rules, the conventions, and where to start.

## Details
- A good guide is short, task-first, and linked from everywhere a new editor lands.
- The guide is living documentation — it must be updated whenever the conventions it teaches change.
- For mykb, the editor guide is the human interface to the style rules that the linters enforce mechanically.
