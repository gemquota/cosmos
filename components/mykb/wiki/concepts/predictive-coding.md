# Predictive Coding

## Summary

Predictive Coding — Neural implementation where higher areas predict lower-level activity.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Predictions flow down; prediction errors flow up and update the model.
- Error units highlight unpredicted input — a novelty signal.
- Accounts for repetition suppression and mismatch responses (MMN).
- Bridges perception, attention, and learning.
