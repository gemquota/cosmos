# Defeasible Reasoning

## Summary
Defeasible reasoning allows conclusions to be retracted when counter-evidence or stronger arguments appear. It matters because real-world knowledge is exception-laden and agents must revise. It is the applied face of non-monotonic logic.

## Details
- Arguments have strength; defeaters can overturn conclusions.
- Default rules express 'normally, unless...' knowledge.
- Essential for belief revision in dynamic environments.
- Open questions: defeasible reasoning in LLM argument generation.
