# Bidirectional Link Ratio

## Summary
The bidirectional link ratio measures reciprocity: if A links to B, how often does B link back?

## Details
- High reciprocity correlates with genuine mutual relevance; persistent one-way links signal either an incomplete stub on one side or a link placed without the target's knowledge.
- Reciprocity should not be enforced blindly — a link from a broad hub to a niche detail page may legitimately be one-way.
- For mykb the ratio is part of the link-score and is reported per page so curators can decide whether the missing backlink is a real gap or a justified asymmetry.
