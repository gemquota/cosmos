# Alias Criteria

## Summary
Alias criteria decide which alternate names a concept needs: synonyms used in the domain, abbreviations, and prior titles that readers may still search for.

## Details
- Aliases are metadata, not pages — recording them keeps search working without multiplying files.
- An alias earns its place by real usage: search logs and recurring questions justify it; theoretical synonyms do not.
- For mykb, aliases complement redirects: aliases handle search and metadata while redirects handle inbound links that name the old slug.
