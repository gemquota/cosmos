# Lexicographic Priorities

## Summary
Lexicographic priorities rank objectives so that any improvement in a higher priority outweighs everything below.

## Details
- Lexicographic priorities rank objectives so that any improvement in a higher priority outweighs everything below.
- Common in safety design: avoid catastrophe first, optimize second.
- Risks: tiny gains at the top priority can block all lower goals; thresholds need care.
- RSIS3 relevance: check-practices failure blocks all pass output — a lexicographic gate.
