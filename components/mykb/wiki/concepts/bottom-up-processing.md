# Bottom-Up Processing

## Summary

Bottom-Up Processing — Perception driven by raw sensory features, independent of expectation.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Features (edges, color, motion) build up to objects and scenes.
- Salience and stimulus strength dominate when bottom-up signals are strong.
- Early visual cortex implements largely feedforward feature analysis.
- Pairs with top-down processing in interactive accounts.
