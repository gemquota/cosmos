# Accuracy Score

## Summary
The accuracy score rates whether the article's claims are correct and supported — the least automatable and most important component.

## Details
- Accuracy is established by verification: claims checked against sources, examples run, commands executed.
- Accuracy failures are the only component that can justify immediate demotion regardless of other scores.
- For mykb, the accuracy score is set by review and verification work, and it gates promotion.
