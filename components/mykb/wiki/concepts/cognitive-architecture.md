# Cognitive Architecture

## Summary
A cognitive architecture is the overall blueprint of an intelligent system: its memory systems, perception channels, control loops, and how they interact. It matters because architecture determines what behaviors are even possible. RSIS3's triad — engine, memory, ideation — is a cognitive architecture at ecosystem scale.

## Details
- Components: working memory, long-term memory, perception, action selection, metacognition.
- Classic examples: SOAR, ACT-R, and blackboard systems.
- Trade-offs: modularity vs. integration, fixed vs. learned structure.
- Open questions: which architectural choices actually drive agent capability.
