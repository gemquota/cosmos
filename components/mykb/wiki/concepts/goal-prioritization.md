# Goal Prioritization

## Summary
Goal prioritization is the mechanism by which an agent orders competing objectives: urgency, importance, and constraints.

## Details
- Goal prioritization is the mechanism by which an agent orders competing objectives: urgency, importance, and constraints.
- Priority schemes are themselves specifications; mis-ordered priorities cause perverse behavior.
- Transparent priority weights make agent behavior auditable.
- RSIS3 relevance: the pulse protocol's goal generation and prioritization is the loop's priority scheme.
