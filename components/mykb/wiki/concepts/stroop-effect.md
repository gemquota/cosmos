# Stroop Effect

## Summary

Stroop Effect — Interference when word meaning conflicts with print color.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Naming the ink color of a color-word (e.g., RED in blue ink) is slower than reading the word.
- The effect indexes automatic processing and attentional control.
- Widely used in cognitive assessment and neuropsychology.
- Example of top-down processing and response competition.
