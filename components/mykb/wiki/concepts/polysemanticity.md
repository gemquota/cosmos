# Polysemanticity

## Summary
Polysemanticity is the phenomenon where a single unit responds to many unrelated inputs, complicating interpretation.

## Details
- Polysemanticity is the phenomenon where a single unit responds to many unrelated inputs, complicating interpretation.
- It arises from superposition: the network packs features densely and shares units.
- Dictionary learning recovers the underlying features, making polysemantic units readable.
- RSIS3 relevance: graph nodes that mix topics are polysemantic; splitting them improves retrieval.
