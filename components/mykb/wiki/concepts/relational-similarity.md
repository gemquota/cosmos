# Relational Similarity

## Summary

Relational Similarity — Similarity defined by matching relations rather than object features.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- 'A is to B as C is to D' matches relations between pairs.
- Relational matches support transfer even when objects differ.
- Expertise shifts attention from features to relations.
- Core to analogy and structure-mapping accounts.
