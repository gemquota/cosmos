# Arousal and Performance

## Summary

Arousal and Performance — Relationship between physiological activation and task performance.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Performance peaks at moderate arousal; extremes impair it (Yerkes-Dodson)
- Task difficulty shifts the optimal arousal level: easy tasks like arousal, hard tasks suffer.
