# Declarative Memory

## Summary
Declarative memory covers facts (semantic) and events (episodic) that can be explicitly stated and queried. It matters because it is the shareable, inspectable part of an agent's knowledge. The mykb wiki is built almost entirely from declarative memory.

## Details
- Subdivided into semantic and episodic memory.
- Explicitly inspectable: readable, editable, linkable as markdown.
- Contrast with procedural memory, which is know-how.
- Open questions: which facts deserve storage versus recomputation.
