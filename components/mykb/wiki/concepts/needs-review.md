# Needs Review

## Summary
Needs-review marks an article that has changed or aged enough that a human must check it before it is trusted again.

## Details
- The state is set by events — a failed freshness check, a broken source, an edit, a promotion — and cleared by review.
- An article can be needs-review and perfectly fine; the label is about the required action, not the current quality.
- For mykb, needs-review articles are listed by review-tag and queued into review sprints.
