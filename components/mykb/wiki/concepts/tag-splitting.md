# Tag Splitting

## Summary
Tag splitting divides a tag that has accumulated two distinct meanings — for example a tag covering both tooling and practice — into two precise tags.

## Details
- The trigger is scale and ambiguity: when reading a tag's articles no longer yields a coherent set, the tag has lost its meaning.
- A split requires deciding each article's side, so it is a reviewed, batched operation with a tag-cascade check afterward.
- For mykb, tag splits are rarer than merges and usually follow a tag-suggestions report showing two clusters inside one tag.
