# Value Drift

## Summary
Value drift is the erosion or transformation of the values a system was built to serve — in AI, the values a model learned or was trained toward; in institutions, mission creep. For long-lived AI systems, drift is the default unless values are actively anchored.

## Details
- **AI-side drift** — continued training, self-improvement, and distribution shift push learned values off course.
- **Institutional analogy** — organizations drift from mission to survival; the same dynamics apply to AI companies and regulators.
- **Detection** — periodic value audits, probe comparisons against frozen reference values, and behavior diffs.
- **Prevention** — anchor snapshots, immutable value layers, and governance that can veto drift.
