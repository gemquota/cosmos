# Learn to Learn

## Summary
Learn to learn is the property of improving one's own learning process: acquiring new tasks faster because of how past tasks were learned. It spans biological education, meta-learning algorithms, and AI systems that reuse skills, and it is the core competence any self-improving system must have.

## Details
- **Manifestations** — meta-learning algorithms, transfer learning, study-skills (for agents: reflection, spaced practice), and curricula.
- **Measure** — learning curves across a sequence of tasks; the meta-metric is how fast the curve rises over time.
- **Mechanism in LLMs** — in-context learning is a form of instant learn-to-learn enabled by pretraining.
- **Why central to RSI** — a system that learns faster is the multiplicative factor in the improvement loop.
- **RSIS3 relevance** — mykb's acquisition passes explicitly aim to make future passes cheaper (denser graph, better practices).
