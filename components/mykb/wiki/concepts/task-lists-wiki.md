# Task Lists

## Summary
Task lists are the wiki's work inventory: each item names the task, the target article, the requester, and the acceptance criteria.

## Details
- They convert flagged problems (cleanup-needed, sources-needed) into assignable work with state.
- A task list without triage is just a pile — priority and effort labels turn it into a queue.
- For mykb, task lists are the execution layer under the review queues and curation sprints.
