# Verified Tag

## Summary
The verified tag marks that a claim, source, or article has been checked against its sources — distinct from reviewed, which covers quality.

## Details
- Verification is about evidence: the tag says 'the sources support this', not 'this is well written'.
- Like reviewed, verified needs a date and ideally the verifier, because verification ages.
- For mykb, verified tags complement unverified flags and feed the verifiability-score.
