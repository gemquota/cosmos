# Expected Value Reasoning

## Summary
Expected value reasoning multiplies each outcome's value by its probability and sums, choosing the highest total.

## Details
- Expected value reasoning multiplies each outcome's value by its probability and sums, choosing the highest total.
- It is the standard rational decision rule and the engine of consequentialist AI ethics.
- Inputs (probabilities, values) are often uncertain; sensitivity analysis helps.
- RSIS3 relevance: loop decisions weigh expected knowledge gains against churn risk.
