# Tags Practice

## Summary
Tags practice defines how tags are chosen: a controlled vocabulary, 3-5 tags per article, each tag naming a real cluster rather than restating the title.

## Details
- Good tags are stable, plural-ish nouns that group genuinely related articles; bad tags are one-off words that never repeat.
- Tags are metadata, not a substitute for links — a tag should point at a category, while a link points at a specific article.
- For mykb, tags practice is enforced by tag-hygiene checks and the tag suggestions pipeline.
