# Effort Labels

## Summary
Effort labels estimate task size — small, medium, large, or story points — so sprints can be planned honestly.

## Details
- Effort is distinct from priority: a small effort on a P1 is a quick win; a large effort on a P2 is a project.
- Effort estimates decay with context; the label should be revisited if the task grows during execution.
- For mykb, effort labels turn the review queue into a plan: edit-sprints can be filled from small-effort items first.
