# Straw Polls

## Summary
Straw polls are informal, non-binding opinion counts used to test where a discussion stands before a formal decision.

## Details
- They are useful for gauging support and useless as verdicts — which is why their results are labeled provisional.
- A straw poll's wording shapes its result, so the question must be neutral and the options complete.
- For mykb, straw polls are used inside RFC discussions to surface where consensus might land.
