# Effect Size Interpretation

## Summary

Effect Size Interpretation — Reading the magnitude of an effect beyond statistical significance.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Common metrics: Cohen's d, correlation, odds ratio, R-squared.
- Context decides what counts as small: 0.2 d is huge for education, small for drugs.
- Report confidence intervals around effects.
- Distinguishes statistical from practical significance.
