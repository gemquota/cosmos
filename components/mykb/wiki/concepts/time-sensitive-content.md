# Time-Sensitive Content

## Summary
Time-sensitive content is material that is correct now and wrong later: version numbers, prices, security statuses, API names.

## Details
- The discipline is labeling: 'as of', 'current version', and dated-claims markers make the expiration visible to readers.
- Curation treats time-sensitive content as a liability class with its own review cadence, shorter than evergreen.
- For mykb, time-sensitive content is flagged at review time and drives the timeliness-score.
