# Open Source AI

## Summary
Open source AI publishes source code and often weights under permissive licenses, enabling inspection and modification.

## Details
- Open source AI publishes source code and often weights under permissive licenses, enabling inspection and modification.
- 'Open' spans a spectrum: code-only, weights-with-restrictions, and fully open.
- Debates center on whether open release is safe at frontier scale.
