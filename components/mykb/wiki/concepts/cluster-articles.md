# Cluster Articles

## Summary
Cluster articles anchor a group of closely related pages — they name the cluster and link its members together.

## Details
- A cluster is discovered by graph analysis or by curation judgment; either way, someone must write the article that holds it together.
- Cluster articles succeed when the membership is coherent: a cluster that is just 'things that start with K' is noise.
- For mykb, cluster articles are reviewed when graph-density metrics reveal tightly linked groups.
