# Popularity Weighting

## Summary
Popularity weighting gives frequently-read articles more influence in metrics and search rankings, using read counts or link traffic as the proxy.

## Details
- Popularity rewards what readers already find, which can entrench the graph's existing winners.
- It is best combined with other weights — popularity alone starves new but better articles.
- For mykb, popularity weighting informs impact-labels and which articles get maintenance priority.
