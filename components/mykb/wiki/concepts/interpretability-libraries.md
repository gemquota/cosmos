# Interpretability Libraries

## Summary
Interpretability libraries package hooks, probes, patching, and visualization into reusable tools.

## Details
- Interpretability libraries package hooks, probes, patching, and visualization into reusable tools.
- Examples include TransformerLens, Sparse Autoencoder toolkits, and attribution libraries.
- Tooling quality determines research velocity; reproducibility requires shared code and configs.
- RSIS3 relevance: the wiki's own scripts (link checks, graph stats) are its interpretability tooling.
