# Split Proposal

## Summary
A split proposal records a proposed article split: the current article, the planned children, and the criteria that justify the division.

## Details
- The proposal should name each child's scope so the split does not just move the bloat around.
- Like merges, splits are decided before they are executed, with the parent-child structure reviewed as part of the proposal.
- For mykb, split proposals follow split-criteria and are tracked in the same queue as merges.
