# Relevance Weighting

## Summary
Relevance weighting emphasizes content that matches the current query or topic context, rather than treating all articles equally.

## Details
- In search it is the core ranking signal; in dashboards it means a topic view weights its own cluster's articles higher.
- Relevance is only as good as the topic model behind it, which is why tags-practice and description quality feed it.
- For mykb, relevance weighting is what makes the knowledge graph's topic views and search behave sensibly.
