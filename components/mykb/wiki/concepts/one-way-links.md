# One-Way Links

## Summary
One-way links point from A to B while B does not link back; they are the complement of reciprocal links.

## Details
- Legitimate one-way links exist — hub-to-detail, glossary-to-article, newer-article-to-established-hub — so one-way status alone is not a defect.
- Persistent one-way links in a cluster deserve review: they often mark a missing backlink or a forced link.
- For mykb, the one-way link report feeds related-link-reciprocity review and the link-score.
