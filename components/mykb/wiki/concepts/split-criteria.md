# Split Criteria

## Summary
Split criteria apply when one page carries two separable concepts: distinct audiences, distinct sources, or a body long enough that navigation suffers.

## Details
- A split creates a parent page that summarizes and links to the children, so readers keep an overview path.
- Splits should be justified by reading behavior — if readers never need one half without the other, splitting is fragmentation.
- For mykb, split proposals pair with parent-child-articles and are reviewed in the same structural queue as merges.
