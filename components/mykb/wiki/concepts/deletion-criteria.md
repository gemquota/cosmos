# Deletion Criteria

## Summary
Deletion criteria cover the narrow cases where removal is right: duplicate content whose merge is complete, pages that were never real articles, or material that is actively wrong with no salvageable value.

## Details
- Deletion should be the rarest lifecycle action because it destroys provenance; when in doubt, archive instead.
- Proposed deletions should pass a review step and leave a record (a delete-proposal) so the decision can be audited.
- For mykb, deletion proposals are tracked like merge and split proposals, with a review queue before anything is actually removed.
