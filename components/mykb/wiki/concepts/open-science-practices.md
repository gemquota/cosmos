# Open Science Practices

## Summary

Open science practices make research transparent and reproducible by sharing methods, data, code, and results. They matter because transparency converts science from a trust-based enterprise into an evidence-based one, letting others verify and build on findings. Openness also changes incentives, rewarding rigor over novelty and making errors visible.

## Details

- **Definition** — Open science spans open methods, open data, open code, open access, and open peer review, each reducing a different opacity.
- **Preregistration** — Committing analysis plans in advance distinguishes confirmatory from exploratory results.
- **Reproducibility** — Shared data and code let others re-run analyses, catching errors and confirming results under different conditions.
- **Publication reform** — Journals that publish regardless of significance reduce publication bias and file-drawer effects.
- **Worked example** — A lab publishes preregistration, raw data, analysis scripts, and a preprint; reviewers reproduce the figures from the repository before publication.
- **Common failure modes** — Open data without documentation, code that runs only on the author's machine, and sharing that is performative rather than usable.
- **Practical relevance** — Open practices are the main institutional answer to the replication crisis, with funders increasingly requiring them.
- **Limits** — Openness does not guarantee correctness or quality; it makes evaluation possible, which is a precondition, not a substitute.
- **Data licensing** — Sharing data responsibly means licensing it, protecting privacy, and documenting provenance so reuse is legal and ethical.
- **Versioning** — Repositories that version data and code alongside paper versions let readers match analyses to the exact artifact used.
- **Worked example** — A replication project downloads a published dataset, runs the shared script, and produces identical figures, validating the pipeline end to end.
- **Costs** — Openness has real costs — curation time, privacy risk, and competition exposure — that institutions must budget for to make it sustainable.
