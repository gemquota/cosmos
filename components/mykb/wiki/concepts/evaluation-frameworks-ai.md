# Evaluation Frameworks for AI

## Summary
Evaluation frameworks organize how models are tested: which capabilities, which datasets, which metrics, which thresholds.

## Details
- Evaluation frameworks organize how models are tested: which capabilities, which datasets, which metrics, which thresholds.
- Good frameworks separate development evals from safety gates.
- Framework rot (stale tasks, gamed metrics) is a standing risk.
- RSIS3 relevance: the pass verifier is an evaluation framework for the bundle.
