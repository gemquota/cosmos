# Prompt Robustness

## Summary
Prompt robustness is a language model's tendency to behave consistently across rewordings, formats, and contexts.

## Details
- Prompt robustness is a language model's tendency to behave consistently across rewordings, formats, and contexts.
- Small prompt changes can flip behavior, which is a reliability and safety problem.
- Testing includes paraphrase sets, adversarial prompts, and instruction changes.
- RSIS3 relevance: wiki templates and practice prompts are tested for robustness across passes.
