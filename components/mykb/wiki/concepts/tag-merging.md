# Tag Merging

## Summary
Tag merging collapses near-duplicate tags (like singular and plural forms, or hyphenated and unhyphenated variants) into a single canonical tag.

## Details
- A merge rewrites the tag across every article that uses either variant, so the cluster reforms correctly.
- Merge decisions are recorded so future curators do not reintroduce the split spelling.
- For mykb, tag merging is part of tag hygiene and is usually batched after a tag report reveals the duplicates.
