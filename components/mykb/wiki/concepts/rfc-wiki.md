# Requests for Comment

## Summary
A request for comment (RFC) is a formal, time-boxed call for input on a proposal, used when a decision needs broad engagement before it is made.

## Details
- An RFC states the proposal, the questions to answer, and the window for comment — then closes with a summary and a decision.
- RFCs scale consensus beyond talk pages by making the discussion a structured, documented event.
- For mykb, RFCs govern structural and policy changes, and their outcomes feed the formal processes.
