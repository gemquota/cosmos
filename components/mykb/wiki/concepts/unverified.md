# Unverified

## Summary
Unverified marks content that has not been checked against its sources — the default state of new claims and the honest label for uncheckable ones.

## Details
- Unverified is not false; it is a warning label that tells readers how much trust to extend.
- Curation's job is converting unverified to verified (or removing the claim) in priority order.
- For mykb, unverified flags drive the verification-needed queue and the verifiability-score.
