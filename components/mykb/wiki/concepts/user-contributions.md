# User Contributions

## Summary
User contributions is the per-editor page listing their activity across the wiki — edits, reverts, flags, and reviews.

## Details
- It answers 'what has this person been working on' and is the basic trust and mentoring tool.
- Contribution lists are most useful filtered by type and time, so the view supports both audit and personal reflection.
- For mykb, user contributions feed editor guides and the promotion of editors to registered status.
