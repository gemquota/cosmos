# Tag Renaming

## Summary
Tag renaming changes a tag's label to a better canonical name, rewriting every article that uses it in one pass.

## Details
- Renames are preferable to creating a new tag and leaving the old one behind — the old tag would linger with a fraction of the articles.
- The rename should be recorded (old name, new name, date) so search and future reports map history correctly.
- For mykb, tag renames follow the same review discipline as slug changes: batch, dry-run, verify.
