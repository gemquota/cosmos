# Timely Articles

## Summary
Timely articles are valuable only while current — tool releases, security advisories, ecosystem shifts — and decay fast after.

## Details
- They need the tightest freshness cadence and should be written shortform to make that cheap.
- A timely article that goes stale is worse than none: it confidently describes a world that no longer exists.
- For mykb, timely articles carry the timeliness-score and are first candidates for update-days.
