# Pending Changes

## Summary
Pending changes is the workflow where edits from lower-trust editors are held for review before appearing in the article.

## Details
- It sits between fully open editing and protection, trading friction for safety.
- The review queue for pending changes must be fast, or the workflow becomes an edit tax.
- For mykb, pending changes is a review-queue specialization for high-risk pages.
