# Curator Guide

## Summary
The curator guide is the manual for curation work: how to promote, review, link-fix, and maintain — beyond plain editing.

## Details
- It operationalizes the criteria articles into procedures: run the checklist, use the queues, record the decisions.
- A curator guide that drifts from actual practice is worse than none; it must be rewritten when the workflow changes.
- For mykb, the curator guide is the bridge between the criteria stubs and the curation sprints that execute them.
