# Mutual Links

## Summary
Mutual links describe the two-article case of reciprocity: A and B each link the other, forming the smallest possible mutually-reinforcing cluster.

## Details
- Mutual links anchor cluster structure — new articles typically join a cluster by first forming mutual links with one or two established members.
- Over-reliance on mutual links can create clique-like clusters that exclude the rest of the graph; diversity still matters.
- For mykb, mutual links are a healthy default for Related blocks between sibling concepts.
