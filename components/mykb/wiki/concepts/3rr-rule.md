# Three-Revert Rule

## Summary
The three-revert rule is the bright line that says an editor may not revert the same article's content more than three times in a day.

## Details
- Its purpose is mechanical, not moral: it forces warring editors to stop and use discussion instead of out-editing each other.
- Like any bright line it is gameable at the edges, so it is paired with the judgment that reverting at all in a dispute is a warning sign.
- For mykb, the 3RR rule is the first enforcement rung before protection and arbitration.
