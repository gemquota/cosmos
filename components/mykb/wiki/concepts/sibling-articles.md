# Sibling Articles

## Summary
Sibling articles share a parent — they are the peer articles beneath the same topic page.

## Details
- Sibling links matter because readers comparing options usually start from siblings, not from the parent.
- A sibling cluster is healthy when its members link to each other, not just up to the parent.
- For mykb, sibling reciprocity is a target of related-link-reciprocity review within clusters.
