# Parameter Pollution

## Summary
Duplicate or ambiguous parameters causing unintended server-side behavior. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Duplicate parameters create ambiguity in how servers choose values
- Attacker-controlled choices can bypass validation and route logic
