# Access Dates

## Summary
Access dates record when a URL was last fetched and found live, anchoring the verification to a moment in time.

## Details
- An access date makes a citation honest: it says 'this URL worked on this date', which is exactly the claim link-rot checks later test.
- Access dates belong in reference entries and are updated by source-review schedules, not by hand.
- For mykb, access dates are part of the source record and feed the freshness and verifiability scores.
