# URI vs URL

## Summary
Distinguishing uniform resource identifiers from locators in web standards. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Every URL is a URI, but not every URI locates a resource
- URNs (names) and URLs (locators) are the two practical URI classes
- Open question — when does a system genuinely need URNs over URLs?
