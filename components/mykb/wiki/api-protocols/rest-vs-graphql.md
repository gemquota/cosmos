# REST vs GraphQL

## Summary
Comparing fixed endpoint shapes with client-driven query languages. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- REST fixes endpoint shapes per resource; GraphQL lets clients shape queries
- GraphQL trades HTTP caching for a typed, over-fetch-free contract
- Open question — where does REST plus sparse fieldsets win?
