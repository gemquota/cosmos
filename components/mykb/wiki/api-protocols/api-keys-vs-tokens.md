# API Keys vs Tokens

## Summary
Comparing static key material with verifiable, expiring tokens. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- API keys are static secrets; tokens are short-lived and verifiable
- Keys simplify but amplify leak damage when rotated rarely
- Open question — how do key hashing schemes protect stored keys?
