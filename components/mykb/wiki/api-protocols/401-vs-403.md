# 401 vs 403

## Summary
Unauthenticated versus unauthorized responses and when each applies. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- 401 challenges for missing or bad credentials; 403 denies authorized-but-forbidden access
- Serving 404 for hidden resources prevents enumeration
- Open question — when should APIs return 404 instead of 403?
