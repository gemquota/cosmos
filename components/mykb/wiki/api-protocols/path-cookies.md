# Path Cookies

## Summary
Restricting cookie delivery to URL prefixes. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Path scoping limits cookies to URL prefixes
- Path is weak isolation: sibling paths can still collide in the jar
- Open question — when is path scoping worth using at all?
