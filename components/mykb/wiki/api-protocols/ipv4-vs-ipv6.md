# IPv4 vs IPv6

## Summary
Comparing 32-bit and 128-bit IP addressing, exhaustion, and transition mechanisms. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- IPv4 exhausts address space while IPv6 offers 128-bit addressing
- Dual-stack and NAT64 bridge the two during transition
- Open question — when does an API need to be IPv6-aware explicitly?
