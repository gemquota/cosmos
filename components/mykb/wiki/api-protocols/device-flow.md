# Device Authorization Flow

## Summary
OAuth flow for input-constrained devices via a user-code URL. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- The device flow shows a code and polls for user authorization
- It suits TVs, CLI tools, and embedded clients without browsers
- Open question — how do headless agent clients authenticate with device flows?
