# API Digest Auth

## Summary
Challenge-response HTTP authentication with hashed credentials. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Digest auth hashes credentials in a challenge-response dance
- It avoids plaintext transport but adds complexity and replay risk
- Open question — has digest auth been fully superseded by bearer tokens?
