# Punycode Domains

## Summary
Internationalized domain names encoded in ASCII via punycode. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- IDNs convert Unicode labels to ASCII using the punycode algorithm
- Homograph attacks arise when confusable scripts map to similar labels
- Open question — how do browsers mitigate lookalike-domain phishing today?
