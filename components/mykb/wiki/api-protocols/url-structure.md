# URL Structure

## Summary
Anatomy of a URL: scheme, authority, path, query, and fragment components. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Schemes, authorities, paths, queries, and fragments each have separate parsing rules
- RFC 3986 defines generic syntax; components must be parsed before any security decision
- Open question — how do URL parsers diverge across browsers and libraries?
