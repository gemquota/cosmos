# Template Injection

## Summary
Server- or client-side template engines evaluating attacker-controlled expressions. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Attacker-controlled template expressions execute in the template engine
- Sandboxed engines still leak via object traversal
- Open question — which template engines are safe against untrusted templates?
