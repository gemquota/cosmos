# Refresh Token Rotation

## Summary
Issuing new refresh tokens per use to bound replay risk. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Each refresh issues a new refresh token and retires the old
- Rotation bounds replay windows and detects theft
- Open question — how does rotation interact with offline clients?
