## Summary
Generated or hand-written SDKs that wrap HTTP APIs for consumers. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Generated SDKs encode contracts as typed, convenient calls
- Version skew between SDK and server needs explicit policy
- Open question — when is a hand-written thin client better than a generated SDK?
