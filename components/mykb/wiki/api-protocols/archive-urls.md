# Archive URLs

## Summary
Archive URLs point at preserved snapshots of a page — via services like the Internet Archive — so a citation survives the original URL's death.

## Details
- Best practice pairs the live URL with an archive snapshot in the same reference entry, giving readers both the current and the durable copy.
- Archive timestamps matter: the snapshot must predate the access date and postdate the claim it supports.
- For mykb, archive URLs are the mitigation for link rot, and archive-timestamp checks verify they actually captured the page.
