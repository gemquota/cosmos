# Clickjacking Defense

## Summary
Techniques that prevent invisible overlays from hijacking user clicks. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Frame-busting headers, CSP frame-ancestors, and anti-clickjacking JS deter overlays
- CSP frame-ancestors is the strongest server-side control
- Open question — how do mobile browsers handle frame embedding policy?
