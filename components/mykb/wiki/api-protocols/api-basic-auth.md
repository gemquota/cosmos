# API Basic Auth

## Summary
Base64 username:password credentials sent in the Authorization header. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Basic auth sends base64 credentials on every request
- It requires TLS and offers no revocation granularity
- Open question — when is basic auth still the pragmatic choice?
