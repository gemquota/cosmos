# Client Credentials Flow

## Summary
OAuth grant for applications acting as themselves. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- The client authenticates directly and receives its own token
- It is for server-to-server, never end-user delegation
- Open question — how do short-lived client tokens rotate signing keys?
