# MIME Types

## Summary
Media types that label payload formats in HTTP Content-Type headers. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Media types like application/json label payload semantics
- Charset, subtype, and vendor prefixes refine the label
- Open question — how strictly should servers enforce declared types?
