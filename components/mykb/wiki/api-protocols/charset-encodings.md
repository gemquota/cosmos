# Charset Encodings

## Summary
Character encodings such as UTF-8, UTF-16, and Latin-1 used in text payloads. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- UTF-8 dominates web payloads; legacy encodings linger in headers
- Misdeclared charsets corrupt parsing and can enable injection
- Open question — which encodings still need explicit handling in 2026?
