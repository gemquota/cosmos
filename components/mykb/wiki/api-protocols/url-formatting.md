# URL Formatting

## Summary
URL formatting rules cover scheme presence, trailing-slash policy, and the choice between canonical and tracking-laden URLs.

## Details
- Canonical, stable URLs are the goal: a source entry should still work when a reader revisits it a year later.
- Formatting rules also cover display: raw URLs in source blocks, readable link text in prose.
- For mykb, URL formatting feeds url-normalization and url-deduplication checks.
