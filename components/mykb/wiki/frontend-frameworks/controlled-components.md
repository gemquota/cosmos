# Controlled Components

## Summary
Inputs whose value and updates are owned by React state. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- React state owns input values and change handlers
- Controlled inputs re-render on each keystroke
- Open question — how do controlled forms scale to large documents?
