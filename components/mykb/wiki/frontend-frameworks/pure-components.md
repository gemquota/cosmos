# Pure Components

## Summary
Components that re-render only when props and state change. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Pure components render from props and state alone
- Purity enables memoization and concurrent rendering
- Open question — how do impure components (Date.now, Math.random) get tamed?
