# Uncontrolled Components

## Summary
Inputs whose value lives in the DOM until read via refs. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- The DOM owns input values until read via refs
- Uncontrolled inputs avoid per-keystroke renders
- Open question — when is uncontrolled the right default?
