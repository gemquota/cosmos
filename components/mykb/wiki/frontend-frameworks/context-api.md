# Context API

## Summary
Prop-drilling-free sharing of values through a component tree. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Context broadcasts values to any depth without prop drilling
- Every context value change re-renders all consumers
- Open question — how do split contexts reduce re-render blast radius?
