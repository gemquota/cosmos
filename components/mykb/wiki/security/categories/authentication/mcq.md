# MCQ

## Summary

MCQ, short for multiple choice question, is a question format in which respondents select the correct answer from a fixed set of options. In security contexts, MCQs appear in training programs, certification exams, and automated evaluation of security knowledge. This entity page was recorded during analysis of session artifacts that touched authentication and tooling, where MCQ content was indexed as an entity. For security programs, MCQs measure knowledge recall efficiently but should be paired with scenario-based assessment of judgment.

## Details

- **Entity record** — this page indexes "MCQ" as an acronym entity observed in analyzed session content, alongside CLI and CSS expansions.
- **Format mechanics** — an MCQ presents a stem, several options, and one or more correct answers; distractor design determines difficulty and fairness.
- **Security training** — MCQs are used to test knowledge of phishing, password hygiene, and authentication best practices in security awareness programs.
- **Assessment value** — well-written MCQs reliably measure recognition-level knowledge but are weaker at testing applied judgment than scenario or performance tasks.
- **Common flaws** — ambiguous stems, implausible distractors, and clue leakage ("all of the above" patterns) reduce measurement quality.
- **Worked example** — a security course asks "Which factor is an example of something you know?" with options including a password, a token, and a fingerprint.
- **Failure modes** — over-reliance on MCQs creates teach-to-the-test behavior and misses hands-on security skills.
- **Practical relevance** — for security programs, MCQs complement simulations and audits; they certify baseline knowledge efficiently.
- **Relation to entity indexing** — acronym pages like this one record how terms were used in sessions so future searches can disambiguate them.
- **Best practice** — MCQs should be piloted, calibrated, and updated as threats and best practices evolve.
- **Bloom level** — MCQs mostly test recognition and comprehension; application-level security skills need simulations, labs, or audits.
