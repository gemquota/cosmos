# Review Sprints

## Summary
Review sprints are focused sessions for reviewing articles — freshness checks, promotion approval, source verification — separated from writing.

## Details
- A review sprint needs a queue and an ordering rule so reviewers work the highest-value items first.
- Review output is recorded: state changes, flags set or cleared, and what the article needs next.
- For mykb, review sprints process the review queues and clear the needs-review backlog.
