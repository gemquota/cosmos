# Edit Sprints

## Summary
Edit sprints are time-boxed efforts focused on editing work — a weekend, a week, or a defined session — with a target set of articles.

## Details
- They work when the scope is concrete: promote these stubs, fix these links, clean these articles.
- A sprint needs a definition of done and a review at the end, or it produces volume without outcomes.
- For mykb, edit sprints are the unit of execution for curation waves, with writing and review sprints as specializations.
