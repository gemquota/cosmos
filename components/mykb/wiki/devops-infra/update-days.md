# Update Days

## Summary
Update days are calendar blocks for applying the edits that keep articles current — the execution half of freshness review.

## Details
- They work from a prepared update list, so the day is spent editing, not deciding what to edit.
- Every update is a candidate for dated-claims, so the article records what changed and when.
- For mykb, update days close the loop that refresh days open and feed the recent-changes feed.
