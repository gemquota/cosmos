# Release Days

## Summary
Release days are when a versioned snapshot of the wiki is cut and published — the bundle, the export, the graph rebuild.

## Details
- Releases make the wiki's state addressable: readers and tools can point at 'release 2026-08' rather than a moving target.
- A release needs a checklist: verification passed, changelog written, archive built, and the dashboard updated.
- For mykb, release days formalize the bundle's snapshot cycle and pair with publish-days.
