# Maintenance Days

## Summary
Maintenance days are recurring calendar blocks for the unglamorous work that keeps the wiki alive: link fixes, source checks, archive runs, dashboard updates.

## Details
- They exist because maintenance does not happen spontaneously — it needs protected time.
- A maintenance day is planned from the generated task backlog and ends with the dashboard showing the effect.
- For mykb, maintenance days absorb the output of audit days and link-fix sprints.
