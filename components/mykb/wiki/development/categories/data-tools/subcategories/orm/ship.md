## Overview

Ship is an entity in the Cosmos session corpus whose description expands to IP, the Internet Protocol — the network-layer protocol responsible for addressing and routing packets between hosts. The related topics listed on the page — ide, isr, orm, rest — reflect the session mix rather than a definition of IP itself, which is a standard part of the TCP/IP stack rather than a development-tool concept.

IP operates in two versions in practice: IPv4, which uses 32-bit addresses and is still the most common, and IPv6, which uses 128-bit addresses and was designed to replace it. IP itself provides best-effort delivery of packets; reliability, ordering, and flow control are layered on top by TCP, while UDP uses IP directly for low-latency datagrams.

## Key Properties

- Addressing: every host on a network needs a unique address within its scope.
- Routing: packets move hop by hop toward the destination network.
- Fragmentation: large packets can be split and reassembled at the destination.
- Best effort: delivery is not guaranteed; upper layers add reliability.
