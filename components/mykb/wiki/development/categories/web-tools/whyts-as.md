# Whyts As

## Summary

Whyts As is the companion entity to Whyts, capturing the "as" framing of the TypeScript question: TypeScript as a language, as a type system, or as a build target. It exists because sessions phrased the rationale in these different roles. Recording the framing keeps the underlying decision legible when the same acronym appears with different modifiers.
