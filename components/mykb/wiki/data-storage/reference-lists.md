# Reference Lists

## Summary
The reference list is the article's complete source inventory, usually at the end, with every inline citation resolving to exactly one entry.

## Details
- A reference list is complete when every citation has an entry and every entry is actually cited — both directions must match.
- Lists are formatted per source-formatting rules so they can be parsed, deduplicated, and monitored.
- For mykb, reference lists are the unit that source-monitoring scans, making citation hygiene machine-checkable.
