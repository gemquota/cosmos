# Power and Sample Size

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Power is the probability of detecting an effect of a given size.
- Sample size depends on effect size, variance, alpha, and power.
- Underpowered tests waste time and miss real effects.
- Run power analysis at design time; document assumptions.
