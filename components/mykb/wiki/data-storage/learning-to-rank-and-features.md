# Learning to Rank and Features

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- LTR trains on relevance labels (clicks, ratings, judgments) to optimize ordering.
- Approaches: pointwise, pairwise, and listwise losses.
- Features: query-doc match, document quality, context, and user signals.
- Feature freshness and logging are as important as model choice.
