# Code in the Wiki

## Summary
Code in the wiki appears as fenced blocks with language tags for multi-line examples and backtick spans for identifiers.

## Details
- Code samples must be runnable-in-principle: no invented APIs, no copied snippets without attribution, and syntax consistent with the article's claims.
- Long code belongs in the repo, linked from the article, not pasted into it.
- For mykb, code conventions are enforced by markdown linting and reviewed for accuracy at promotion time.
