# Bayesian Experiment Analysis

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Bayesian analysis combines priors with data to yield posterior distributions.
- Decisions use posterior probabilities (e.g., P(B > A)), not p-values.
- Priors encode prior knowledge; sensitivity checks test their influence.
- Interpretable for stakeholders but depends on model assumptions.
