# Soda and dbt Tests

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- dbt tests: unique, not_null, relationships, accepted_values, plus custom SQL tests.
- Soda checks run SQL-like assertions with alerting and anomaly detection.
- Both run in CI and on schedules, blocking bad promotions.
- They embed quality gates where the transformation happens.
