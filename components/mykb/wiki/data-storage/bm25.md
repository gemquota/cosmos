# BM25

## Summary
BM25 (Best Matching 25) scores documents by query terms using a probabilistic model with term-frequency saturation and document-length normalization. It is the default lexical ranker in Lucene, Elasticsearch, and SQLite FTS5, and the strong half of hybrid search. For exact-term recall it still beats many embedding systems.

## Details
- **Key idea** — the first occurrence of a term matters most (saturation); short documents are preferred when they mention a term (length normalization).
- **Parameters** — k1 controls term-frequency saturation (~1.2 typical), b controls length normalization (~0.75 typical); tuning shifts precision and recall.
- **Comparison** — BM25 vs TF-IDF: BM25 adds saturation and normalization, which is why it dominates in practice; both are lexical and keyword-dependent.
- **Worked example** — query 'HNSW product quantization' over a tech wiki: BM25 ranks notes that literally use those terms, while a vector search may rank conceptually similar but differently worded notes.
- **Role in hybrid** — BM25 scores are not comparable with cosine scores, which motivates rank-based fusion like reciprocal rank fusion.
- **mykb relevance** — any future FTS layer (SQLite FTS5 or Elasticsearch) will expose BM25 ranking over wiki text.
