# Images in the Wiki

## Summary
Images in the wiki are allowed when they carry information — diagrams, screenshots of tool output, architecture figures — not decoration.

## Details
- Every image needs a caption, alt text, and a source attribution; undecorated images are accessibility failures and maintenance debt.
- Image files are heavy and should be stored with the bundle, referenced by stable paths, and optimized for web use.
- For mykb, image conventions are conservative: most concepts are better served by diagrams-in-wiki using text-based tools.
