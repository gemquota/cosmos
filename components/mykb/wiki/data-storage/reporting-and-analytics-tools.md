# Reporting and Analytics Tools

## Summary

Analytics tools range from notebooks to governed BI platforms.
Each tool trades self-service against governance.
The right portfolio covers exploration, reporting, and embedding.
Tool sprawl creates metric chaos; a small, governed portfolio beats a wide one.

## Details

- BI platforms: Looker, Power BI, Tableau, Metabase.
- Open-source serving: Apache Superset, Metabase.
- Notebooks and SQL clients serve analysts and data scientists.
- Embedded analytics SDKs put charts in products.
- Evaluate on semantic-layer support, governance, and cost.
- Standardize on one semantic layer regardless of tool.
- Evaluate total cost including training and governance.
- Tool selection is a governance decision as much as a technical one.
