# Collaborative and Content Filtering

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Collaborative filtering uses user-item interaction patterns ('people like you liked...').
- Content filtering uses item attributes and user profiles.
- Hybrids combine both to handle cold start and sparsity.
- Matrix factorization, neighborhood methods, and two-tower models are common implementations.
