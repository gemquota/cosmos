# Open Data Formats

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Open formats (CSV, JSON, Parquet, ORC, Arrow) avoid vendor lock-in.
- They enable tool interchange and long-term archival.
- Tradeoffs: schema richness, compression, and ecosystem support.
- Prefer open, documented formats for exchange boundaries.
