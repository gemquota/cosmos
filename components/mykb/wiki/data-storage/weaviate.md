# Weaviate

## Summary
Weaviate is an open-source vector database that ships vector, lexical (BM25), and hybrid search in one engine, plus modular integrations for embedding models. It lowers the integration cost of RAG pipelines.

## Details
- **Features** — hybrid search with fusion, property filtering, object storage with vector index, and GraphQL/REST APIs.
- **Modules** — pluggable embedding providers and vectorizers; multi-tenancy support.
- **Agent relevance** — Weaviate demonstrates the hybrid-search pattern mykb's TF-IDF + embedding paths emulate.
