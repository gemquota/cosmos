# Infobox Practice

## Summary
An infobox is the compact set of key facts — type, status, source count, related cluster — rendered at the top of an article for at-a-glance reading.

## Details
- Infoboxes work when the fields are standardized and machine-generated from frontmatter; hand-maintained boxes drift from the article.
- The infobox is metadata made visible, so its source of truth is the frontmatter, not a second copy.
- For mykb, infobox practice is optional and derived: the health dashboard renders the same fields the frontmatter already holds.
