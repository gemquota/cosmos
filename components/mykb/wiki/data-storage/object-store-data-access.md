# Object Store Data Access

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Object stores (S3, GCS, ADLS) are the substrate for data lakes.
- Access patterns: bulk scan, range reads, and metadata listing.
- Consistency, request costs, and listing latency shape layout.
- Table formats add ACID and transactional metadata on top.
