# Fixture Data and Seeding

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Fixtures are curated records with known expectations.
- Seeding loads fixtures into databases before tests.
- Version fixtures with the code that asserts on them.
- Beware fixture drift when schemas evolve.
