# Reference Blocks

## Summary
The reference block is the article section that lists sources: URLs, titles, dates, and access information formatted consistently.

## Details
- Every claim that goes beyond common knowledge should trace to an entry here, which makes the block the article's evidence layer.
- Reference formatting must be machine-checkable so deduplication and link-rot checks can run over it.
- For mykb, reference blocks follow source-formatting rules and are the input to source-monitoring.
