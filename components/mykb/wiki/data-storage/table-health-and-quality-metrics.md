# Table Health and Quality Metrics

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Health metrics: freshness, row-count stability, schema drift, null rates, and query latency.
- Publish metrics per table so teams can react before users complain.
- Trends matter: a slow drift in nulls is a silent data-quality failure.
- Automate checks in CI and alerting; keep the scorecard in the catalog.
