# Sequential Testing

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Classic fixed-horizon tests break when you peek at interim results.
- Sequential methods (group sequential, always-valid p-values) allow early stopping.
- They trade some sample size for flexible monitoring.
- Use when time-to-decision matters or stopping early is valuable.
