# Cohort and Retention Analytics

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Cohorts group users by a shared start event (signup month, install week).
- Retention tables show what fraction of each cohort returns per period.
- Define return events and windows carefully; semantics change numbers.
- Cohort analysis drives activation, churn, and lifecycle insights.
