# Lakehouse Engines Comparison

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Spark: heavyweight ETL and large-scale processing with full lakehouse features.
- Trino: interactive SQL federation and ad-hoc analytics over lake files.
- DuckDB: single-node embedded analytics for local and mid-size workloads.
- Cloud engines (Athena, BigLake, Synapse serverless) trade flexibility for convenience.
