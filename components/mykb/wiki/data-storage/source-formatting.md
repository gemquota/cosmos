# Source Formatting

## Summary
Source formatting is the fixed layout of a reference entry: title, publisher or site, publication date, URL, and access date, in a predictable order.

## Details
- Uniform formatting is what lets tooling parse the reference block: link-rot checks, deduplication, and freshness reports all depend on the shape being consistent.
- The format should be documented in the style guide and enforced by linting rather than left to each writer's taste.
- For mykb, source formatting is the contract between articles and the source-monitoring tooling.
