# Teradata and Legacy Warehouses

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Teradata pioneered shared-nothing MPP warehousing with linear scalability.
- Its BTEQ/TPT tooling and SQL dialect shaped generations of data engineers.
- Modern stacks migrate to cloud MPP or lakehouse for cost and elasticity.
- Legacy skills still matter: many large enterprises run Teradata today.
