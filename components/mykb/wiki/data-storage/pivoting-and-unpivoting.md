# Pivoting and Unpivoting

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Pivot turns row values into columns; unpivot turns columns into rows.
- Long form suits aggregation and charting; wide suits matrices and exports.
- SQL support varies (CROSSTAB, CASE, FILTER, UNPIVOT).
- Know the target form before reshaping: tools consume one shape best.
