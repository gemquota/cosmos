# Mermaid in the Wiki

## Summary
Mermaid is the diagram-as-code language used in the wiki's markdown blocks for flowcharts, sequence diagrams, and graphs.

## Details
- Mermaid blocks live in fenced code blocks with a mermaid language tag, render in Obsidian and the web graph, and validate like code.
- The convention includes: small focused diagrams, caption lines, and a rule that the diagram never contradicts the surrounding prose.
- For mykb, Mermaid blocks are the preferred diagram format because they version cleanly with the articles.
