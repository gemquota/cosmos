# Inline Citation Style

## Summary
Inline citation style defines how a source reference appears at the point of use: bracketed numbers, author-year, or link-markdown, chosen once for the whole wiki.

## Details
- The chosen style must be machine-parseable so reference blocks and inline markers can be cross-checked.
- Consistency is the point — switching styles between articles makes the evidence layer unreadable.
- For mykb, inline citations are typically wikilinks to reference entries plus source URLs, and the style is enforced by linting.
