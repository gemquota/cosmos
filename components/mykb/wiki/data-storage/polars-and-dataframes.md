# Polars and DataFrames

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Polars is an in-memory dataframe library with lazy evaluation and a vectorized query engine.
- Its expression API composes transformations without intermediate copies.
- Streaming mode handles data larger than RAM.
- Pandas users get similar ergonomics with often 5-10x speedups.
