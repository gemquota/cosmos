# Indexes

## Summary
An index is a navigation page that lists articles by a scheme — alphabetical, by topic, by status — making the collection navigable without search.

## Details
- Indexes are the wiki's front door: every reader lands on one, so index quality shapes first impressions.
- A good index is machine-maintainable: generated from frontmatter so it never drifts from the articles it lists.
- For mykb, indexes are hub pages maintained by the curation pipeline, and index freshness is part of the health dashboard.
