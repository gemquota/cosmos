# Tables in the Wiki

## Summary
Tables in the wiki are for comparisons and structured data — feature matrices, version lists, parameter tables — where rows and columns carry real information.

## Details
- A table should be readable as markdown and as rendered HTML, with a header row and consistent cell types per column.
- Tables are not a substitute for prose: if the comparison is subtle, prose explains it and the table summarizes it.
- For mykb, table conventions are part of markdown linting and infobox practice.
