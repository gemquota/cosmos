# Multiple Comparisons Corrections

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Testing many metrics/hypotheses inflates the chance of false positives.
- Bonferroni controls family-wise error; Benjamini-Hochberg controls FDR.
- Pre-register which corrections apply to which analyses.
- Corrections reduce power; prioritize hypotheses instead of testing everything.
