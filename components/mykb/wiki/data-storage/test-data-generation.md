# Test Data Generation

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Test data should cover happy paths, edge cases, and error conditions.
- Generate deterministically with seeds for reproducible tests.
- Property-based generation finds cases hand-written fixtures miss.
- Keep test data small and fast; scale up for performance tests.
