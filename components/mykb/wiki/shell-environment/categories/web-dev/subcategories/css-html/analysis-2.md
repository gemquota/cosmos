## Kinds of Analysis

Code analysis inspects programs statically or dynamically to find bugs, complexity, and improvement opportunities. Data analysis summarizes and models datasets to answer questions. Requirements analysis turns vague intent into testable specifications. In web development the three blur together: analyzing a page's behavior means inspecting its markup, its network calls, and the data it renders.

## Method

Good analysis is iterative and evidence-based: form a hypothesis, gather measurements, test, and revise. Tools include profilers, loggers, debuggers, and scripts that slice datasets.
