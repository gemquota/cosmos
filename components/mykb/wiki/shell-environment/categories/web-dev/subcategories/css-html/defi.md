## Decentralized Finance

DeFi — decentralized finance — refers to financial services rebuilt on public blockchains using smart contracts instead of banks and intermediaries. Users interact through wallets and web frontends; the contract, not a company, holds custody and executes the rules.

Common building blocks:

- **DEXes** — automated market makers let users swap tokens without an order book or counterparty.
- **Lending protocols** — deposits earn interest, and loans are over-collateralized and liquidated automatically.
- **Stablecoins** — assets pegged to fiat or algorithmically stabilized, used as trading and settlement units.
- **Liquidity pools and yield farming** — users supply assets and earn fees or governance tokens.
- **Oracles** — off-chain price feeds that smart contracts trust; their manipulation is a known attack surface.

The ecosystem inherits all the risks of permissionless code: smart-contract exploits, impermanent loss in pools, oracle attacks, and front-running. Regulatory status varies by jurisdiction, and interfaces must be treated as software with a security review cycle like any other. In this knowledge base the term appears in frontend and shell sessions — consistent with DeFi's heavy dependence on web UIs, DOM-driven dashboards, and deployment tooling, which explains the bash and CI/CD tags.

## DeFi and the Web Stack

Every DeFi application is a web application first: wallets connect through browser extensions, dashboards render price charts with canvas or SVG, and deployment pipelines push contract addresses and frontend bundles together. That is why the term clusters with DOM, CSS, and shell-tooling tags in the knowledge base.
