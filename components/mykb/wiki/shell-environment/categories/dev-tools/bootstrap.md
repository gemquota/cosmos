## Bootstrap

Bootstrap is a CSS framework for developing responsive and mobile-first websites. Provides a grid system, components, and utilities.

## Overview

Bootstrap is the CSS framework known for its responsive grid, ready-made components, and utility classes. Its 12-column grid with breakpoints lets layouts reflow across phone, tablet, and desktop widths without custom media queries. Components — buttons, forms, navbars, modals, and cards — ship as styled, accessible HTML patterns, and utilities adjust spacing, typography, and visibility. Bootstrap accelerates prototyping and provides consistent styling out of the box.

## Details

- Grid: rows and columns compose layouts; breakpoints (sm, md, lg, xl) control when columns stack or align.
- Components: prebuilt patterns reduce custom CSS; they are customizable via variables and themes.
- Utilities: spacing, flexbox, and display helpers cover the majority of layout tweaks without new stylesheets.
- Customization: CSS variables and Sass sources let teams override defaults, so sites need not look generic.
- Trade-offs: the framework adds CSS weight and a recognizable look; teams often pair it with a build step or purge unused styles.
- Alternatives: utility-first frameworks like Tailwind overlap in purpose but structure styling differently.

The name also carries a general meaning in dev tooling: bootstrapping is the process of initializing a project, environment, or service from nothing — installing dependencies, generating configs, and seeding state, often driven by shell scripts. Sessions tagged with bash, bun, ide, and json likely touch both senses: scaffolding a project that then uses Bootstrap, or bootstrapping tooling whose config is JSON.
