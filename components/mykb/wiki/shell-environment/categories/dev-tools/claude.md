## Overview

Claude is an AI assistant created by Anthropic, known for a design emphasis on helpfulness, harmlessness, and honesty. It is accessed through the Anthropic API for text generation and analysis, and through coding products such as Claude Code for agentic work inside repositories. Working with an AI assistant in a development workflow changes how tasks are decomposed: instead of writing every line, the developer describes intent, reviews generated code, and iterates on failures. Effective use depends on clear context — repository structure, constraints, and acceptance criteria — and on verification, since generated code must be tested like any other code.
