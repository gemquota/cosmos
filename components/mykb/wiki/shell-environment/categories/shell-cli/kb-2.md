## Two Readings

KB is a two-way acronym. In data contexts it abbreviates **kilobyte** — historically 1024 bytes, though the SI definition is 1000 bytes and the unambiguous unit for 1024 is KiB. The distinction matters in file sizes, bandwidth, and memory accounting: tools and cloud billing can disagree by 2.4 percent.

In knowledge work, KB abbreviates **knowledge base** — an organized collection of knowledge with retrieval, linking, and provenance. This wiki is itself a KB: articles carry frontmatter, link through wikilinks, and are searched via indexes and graph traversal.
