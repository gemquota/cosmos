# Reputation Score

## Summary
The reputation score rates trustworthiness for sources and authors: track record, editorial process, and verification history.

## Details
- For sources it is built from domain-trust, publisher-trust, and author-credentials; for articles, from verification history and review outcomes.
- Reputation is earned slowly and lost fast — a single fabrication should tank a source's score.
- For mykb, the reputation score is recorded per source at vetting and feeds the trust-score.
