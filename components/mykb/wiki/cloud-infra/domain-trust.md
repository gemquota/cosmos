# Domain Trust

## Summary
Domain trust is a coarse first-pass signal: official documentation domains, academic repositories, and reputable publishers are treated as trusted by default.

## Details
- Domain is a heuristic, not a verdict — a trusted domain can host low-quality pages and a small domain can host rigorous work.
- Trust classes should be explicit (trusted, neutral, review-required) and recorded per source.
- For mykb, domain trust is one component of source-vetting and feeds the trust-score.
