# Encrypted Inference

## Summary
Running model inference on encrypted data using homomorphic encryption or secure protocols

## Details
- Computation proceeds without revealing inputs to the host.
- Overheads remain high relative to plaintext inference.
- Used for sensitive verticals like health and finance.
- Complemented by secure-enclaves-inference.
