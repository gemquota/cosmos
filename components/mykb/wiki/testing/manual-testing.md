# Manual Testing

## Summary
Manual testing uses human judgment to explore, verify, and evaluate software without scripts. It remains essential for UX judgment, accessibility feel, exploratory discovery, and areas where automation cost exceeds the value it returns.

## Details
- Kinds: exploratory, scripted checklist-driven, usability, and user acceptance testing.
- Strengths: pattern recognition, subjective quality assessment, and low setup for new features.
- Weaknesses: slow, unrepeatable, and no regression protection without documentation.
- Capture sessions and results so manual work stays reviewable and audit-friendly.
- Automate what repeats; keep humans for what needs judgment.
- Manual plans should reference expected behaviors from acceptance criteria.
- Pair manual and automated work: humans find, scripts protect.
