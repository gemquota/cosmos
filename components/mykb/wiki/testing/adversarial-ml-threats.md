# Adversarial ML Threats

## Summary
Attack classes targeting machine learning systems from evasion to poisoning

## Details
- Include evasion, poisoning, extraction, and inference attacks.
- Attack surface grows with deployment and tooling.
- Testing requires red-team-processes and evaluation sandboxes.
- Defense is layered: data, model, and runtime controls.
