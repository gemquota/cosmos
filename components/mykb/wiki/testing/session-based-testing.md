# Session-Based Testing

## Summary
Session-based testing structures exploratory work into time-boxed sessions with charters, notes, and debriefs. It makes exploratory testing measurable, reportable, and repeatable instead of invisible effort.

## Details
- Session structure: charter, duration of 45 to 90 minutes, notes, bugs found, and debrief.
- Charters state mission and scope: explore X to find Y using Z.
- Metrics: sessions per area, bugs per session, and charter coverage.
- Debriefs capture learning and prioritize follow-ups.
- Tools: session sheets, spreadsheets, or dedicated session-based apps.
- Combines exploration rigor with management visibility.
- Feed discovered bugs into regression suites and risk profiles.
