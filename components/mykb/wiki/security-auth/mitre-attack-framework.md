# MITRE ATT&CK Framework

- MITRE ATT&CK catalogs adversary behavior as tactics (goals) and techniques (methods), spanning enterprise, cloud, mobile, and ICS.
- It gives defenders a shared language for detection coverage, red-team planning, and threat modeling.
- Coverage analysis maps detections to techniques, exposing gaps in monitoring.
- For mykb: the framework is the vocabulary for describing what agent and memory-system defenses actually stop.
