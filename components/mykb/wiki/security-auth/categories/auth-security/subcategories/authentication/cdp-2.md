## Overview

CDP is an acronym with several well-known expansions. In web development it is the Chrome DevTools Protocol, a JSON-based protocol that lets external tools drive, inspect, and debug Chromium browsers — controlling pages, evaluating scripts, capturing network traffic, and taking screenshots. In the data world it stands for Customer Data Platform, software that unifies customer data from many sources. In authentication contexts it may also abbreviate Continuous Deployment Pipeline or a credential distribution protocol.

## Details

- Chrome DevTools Protocol: client libraries connect over a WebSocket, send commands, and receive events; it powers headless testing, browser automation, and performance tracing.
- Customer Data Platform: ingests events and profiles, builds unified identities, and serves segments to marketing and product systems; privacy and consent are central concerns.
- CI/CD reading: a deployment pipeline moves builds through stages — build, test, and release — with gates and rollback paths.
- Cloud and shell: AWS-based stacks configure CDP-adjacent tooling via scripts, and Bash drives the automation that exercises the protocol.
- Security: browser automation via CDP must treat the debugging endpoint as privileged; exposing it without auth allows remote control of the browser.
