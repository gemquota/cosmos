## Overview

Cognitive Architecture refers to the fixed structure — memory systems, perception, attention, reasoning, and action selection — within which cognitive processes operate. In AI, the term describes the organization of an agent: what it remembers, how it decides, and how it acts. The page was recorded in a session categorized as API, Mobile, and Security, linking the concept to authenticated, networked agent behavior.

## Classical Architectures

Classical cognitive architectures such as SOAR and ACT-R specify modules for working memory, long-term memory, and production rules that select actions. They were designed to model human cognition and to make the internal reasoning traceable. Their influence persists in agent design: structured memory, explicit goals, and inspectable decision steps are all inherited ideas.

## Agent Architectures

Modern agent architectures wrap a language model in a loop with tools, memory, and orchestration: perception becomes tool results and context, reasoning becomes model generation, and action becomes tool calls and API requests. Memory is usually tiered — working context, episodic records, and long-term stores — mirroring the classical split. The API and Security categories reflect that such agents act through authenticated services.
