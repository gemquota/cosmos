## Base Radius 2

Base Radius is an identifier observed in sessions categorized as API, Frontend, Mobile, and Security, with no single meaning fixed by the notes. Two readings fit the context best, and the page records both. The first is geometric: a base radius is the reference size used by a physics or layout system, the radius against which other measurements are scaled. The second is protocol-level: RADIUS, the Remote Authentication Dial-In User Service, a long-standing protocol for centralized authentication, authorization, and accounting.

In the geometric reading, a base radius defines the starting size of a circle, a rounded corner, or a collision body. Simulations tune objects relative to a base value so that scaling behaves predictably, and UI systems use a base radius to keep rounded corners consistent across components. The frontend and mobile tags on this page fit this reading well.

The security reading is just as plausible: RADIUS authenticates users against a central server and is widely used for network access, VPNs, and Wi-Fi authentication. It exchanges credentials over a shared secret, supports challenge-response, and produces accounting records for usage. The API and Security tags fit this reading, and the term's presence in authentication-related sessions makes it a strong candidate.

Recording both readings is deliberate: the sessions did not resolve the ambiguity, and asserting one meaning would discard evidence. The related entities below list the neighboring authentication pages observed in the same sessions, giving the identifier a place in the wider vocabulary of the knowledge base.



The geometric and protocol readings also share a practical lesson: base values define the reference against which everything else is measured. In simulation and layout, changing the base radius rescales the whole system predictably; in authentication, RADIUS defines the central reference for who is allowed on the network. Recording the identifier with both readings preserves the session evidence and lets a future session pick the right one.
