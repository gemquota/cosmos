# Data Breach Response

- Breach response executes the incident-response lifecycle under pressure: contain, eradicate, recover, and learn.
- A good response depends on pre-planned playbooks, contact lists, evidence preservation, and legal/comms involvement.
- Notifications (regulators, users, partners) are time-boxed by law, so detection and classification speed directly affect liability.
- For mykb: a breach playbook should cover memory data specifically — what could leak, how to verify, whom to tell.
