# Security Champions

- Security champions are developers embedded in product teams who own security practice locally: threat modeling, review culture, and tooling adoption.
- The model scales security expertise without a security team per squad, and it builds a durable security culture.
- OWASP's Security Culture project covers the people-and-practice side of sustaining champions.
- For mykb: champions could own per-domain security pages, keeping guidance current as the graph grows.
