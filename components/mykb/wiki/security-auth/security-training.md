# Security Training

- Security training covers awareness for everyone (phishing, password hygiene) and role-specific skills for engineers and admins.
- NIST SP 800-50 remains the reference for building a security awareness and training program.
- Effective programs are continuous and measured, not annual checkbox exercises.
- For mykb: agent and developer guidance should be captured in wiki pages so training material lives beside the system it describes.
