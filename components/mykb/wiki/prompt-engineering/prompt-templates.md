# Prompt Templates

## Summary
Parameterized prompt skeletons with slots for dynamic content

## Details
- Templates fix structure while varying slots: task, context, examples.
- Reduce duplication and enforce consistent formatting.
- Templates need validation and versioning.
- Support system-prompt-design.
