# Image Generation Prompts

## Summary
Prompt crafting for text-to-image models to control composition and style

## Details
- Detailed subject, style, lighting, and composition cues improve results.
- Negative prompts and seed control add determinism.
- Iterative refinement is standard practice.
- Evaluate via multimodal-evaluation.
