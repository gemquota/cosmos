# Language Consistency

## Summary
Keeping model input and output language stable and coherent across a system

## Details
- Prevents mid-conversation language switching and mixed output.
- System prompts and post-checks enforce language norms.
- Matters for multilingual-prompting deployments.
- Evaluated in instruction-following checks.
