# Multilingual Prompting

## Summary
Crafting prompts that work across languages and cultural contexts

## Details
- Prompt design, examples, and evaluation must be language-aware.
- Translation of prompts can lose nuance.
- Mixed-language data improves robustness.
- Supports translation-agents and global products.
