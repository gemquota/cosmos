# Monte Carlo Tree Search for LLMs

## Summary
Applying MCTS planning to language-model reasoning and decision problems

## Details
- MCTS balances exploration and exploitation over reasoning steps.
- Rollouts estimate value where rewards are sparse.
- Used in reasoning benchmarks and game-like tasks.
- Computationally expensive without strong value models.
