# Style Adaptation

## Summary
Adjusting model output style to match audience, brand, or genre requirements

## Details
- Style guides in prompts encode tone, vocabulary, and structure.
- Few-shot examples outperform abstract style descriptions.
- Excess style pressure can reduce clarity.
- Used with persona-prompting and tone-control.
