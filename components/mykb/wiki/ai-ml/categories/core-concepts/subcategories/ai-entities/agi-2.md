# AGI

## Overview
AGI stands for Artificial General Intelligence: a hypothetical machine intelligence that matches or exceeds human cognitive ability across the full range of tasks a person can perform, rather than excelling at a narrow benchmark. It stands in contrast to narrow AI, which is optimized for a single domain such as translation, image recognition, or code completion. In the Cosmos corpus the acronym appears as a session topic tag, so this entity page gives that usage a stable, resolved definition.

## Key Ideas
- **Generality** — one system handles many task families instead of one specialized model; generality, not raw capability in any single task, is the defining property.
- **Benchmarks** — there is no universal test for generality, so evaluation must sample diverse held-out tasks spanning reasoning, planning, learning, and common-sense understanding.
- **Safety** — high capability raises alignment, control, and governance questions, which is why AGI discussion in this corpus connects to capability controls and alignment practice.
- **Timeline uncertainty** — predictions about arrival vary widely and are not a reliable planning basis; engineering treats AGI as a possibility to prepare for, not a dated event.
- **Route debate** — researchers disagree on whether scaling current architectures or designing new ones is the more plausible route, and the debate informs where evaluation effort goes.
