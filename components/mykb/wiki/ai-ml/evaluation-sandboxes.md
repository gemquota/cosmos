# Evaluation Sandboxes

## Summary
Isolated environments for safely testing agents and models at full capability

## Details
- Sandboxes contain side effects: network, filesystem, and tool access are virtualized.
- Allow stress-testing without production risk.
- Key for red-teaming and capability measurement.
- Complement simulation-environments-agents for agent evals.
