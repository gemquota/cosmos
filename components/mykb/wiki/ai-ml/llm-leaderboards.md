# LLM Leaderboards

## Summary
Public rankings comparing models on standardized benchmark suites

## Details
- Examples: LMArena, Open LLM Leaderboard, and vendor-specific charts.
- Aggregate scores hide task-level variance.
- Useful for shortlisting, not for final model-selection decisions.
- Pair with cost and latency data for real trade-offs.
