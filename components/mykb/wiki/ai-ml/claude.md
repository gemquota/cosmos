# Claude

## Summary
Claude is Anthropic's assistant model family, built with a focus on safety, long context windows, and tool use. Its documentation and model cards are reference material for prompt and agent engineering.

## Details
- Anthropic publishes detailed model cards, system-prompt guidance, and tool-use documentation.
- Known for large context windows and strong writing/coding behaviour.
- Constitutional AI underpins its alignment story.
- RSIS3 relevance: Claude-class models are common backbones for agentic systems like RSIS3's L1 loops.
