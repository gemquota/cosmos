# Score Components

## Summary
Score components are the individual sub-scores — content, links, metadata, readability, timeliness — that combine into the composite article score.

## Details
- Each component must be defined, measurable, and independent; overlapping components double-count quality.
- The weighting of components is a policy decision, recorded so scores stay comparable over time.
- For mykb, the component set is fixed by the scoring rubric and reviewed when the rubric is revised.
