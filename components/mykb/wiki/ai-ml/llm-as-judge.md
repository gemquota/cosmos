# LLM-as-Judge

## Summary
Using a language model to score or compare outputs instead of human annotation

## Details
- Judges score on rubrics, pairwise preference, or pointwise quality.
- Fast and scalable but biased by judge model preferences.
- Calibration checks and human audits improve trust.
- Core to modern evals-harness workflows.
