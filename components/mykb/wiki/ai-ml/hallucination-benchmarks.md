# Hallucination Benchmarks

## Summary
Suites measuring how often models produce unfaithful or fabricated content

## Details
- Cover closed-book QA, summary faithfulness, and citation accuracy.
- Metrics include factuality scores and human-verified error rates.
- Used with hallucination-mitigation techniques for regression testing.
- A key input to llm-regression-testing.
