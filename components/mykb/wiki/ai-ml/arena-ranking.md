# Arena Ranking

## Summary
Global model rankings derived from crowdsourced pairwise vote data

## Details
- Users vote on anonymous model pairs; Elo-style methods aggregate votes.
- Reflects real user preferences at scale.
- Voting distributions and drift make rankings noisy.
- A popular complement to benchmark leaderboards.
