# CSS Transitions

## Summary
Interpolating property changes over a duration. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Transitions interpolate between property states over duration and easing
- Not every property is animatable; animatable ones vary in cost
- Open question — when should transitions yield to WAAPI?
