# Inline SVG

## Summary
Embedding SVG markup directly in HTML for styleable graphics. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Inline SVG is DOM-addressable, styleable, and animatable
- Repeated inline SVGs bloat HTML; symbols and sprites mitigate
- Open question — how do framework pipelines optimize SVG usage?
