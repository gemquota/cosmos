# clamp() in Practice

## Summary
Fluid CSS values clamped between minimum and maximum bounds. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- clamp(min, preferred, max) creates fluid type and spacing
- The preferred value usually uses vw mixed with rem
- Open question — where does clamp fail for accessibility zoom?
