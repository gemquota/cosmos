# touch-action CSS

## Summary
Declaring how browser touch gestures may manipulate an element. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- touch-action declares which browser gestures an element allows
- pan-x, pan-y, and none decide pinch, scroll, and zoom handling
- Open question — how does touch-action map to pointer events?
