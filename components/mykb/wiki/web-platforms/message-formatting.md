# Message Formatting

## Summary
ICU message syntax for interpolating translated strings with placeholders. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- ICU MessageFormat embeds placeholders, plurals, and gender in strings
- Positional arguments break translators; named arguments survive reordering
- Open question — will MessageFormat 2 become the shared standard?
