# content-visibility CSS

## Summary
Skipping rendering of off-screen content to cut layout cost. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- content-visibility: auto skips rendering off-screen content
- It trades memory for jump-scroll accuracy if sizes aren't reserved
- Open question — how does it interact with search and a11y trees?
