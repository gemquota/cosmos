# px vs rem

## Summary
When fixed pixels or root-relative rems suit a design. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- px is absolute; rem scales with root font size
- Accessibility zoom favors rem for text sizing
- Open question — should spacing use rem, em, or px in 2026?
