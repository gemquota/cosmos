## Summary
Resources that delay first paint until fetched and parsed. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- CSS and synchronous scripts block first render
- Inline critical CSS and async scripts unblock it
- Open question — how does streaming HTML reduce blocking?
