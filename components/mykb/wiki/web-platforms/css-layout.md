# CSS Layout

## Summary
CSS layout is how elements get positioned and sized: the box model, normal flow, flexbox for one-dimensional arrangement, and grid for two-dimensional. Modern layout makes responsive design declarative.

## Details
- Flexbox aligns a row or column; grid defines rows and columns with placement and gaps.
- Responsive layouts use media queries, container queries, and fluid units (clamp, fr, minmax).
- RSIS3 relevance: wiki-rendered pages and dashboards share the same layout principles.
