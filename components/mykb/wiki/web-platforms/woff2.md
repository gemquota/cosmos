# WOFF2 Format

## Summary
The compressed web font container format. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- WOFF2 compresses font tables with Brotli-style preprocessing
- It is the default shipping format for modern webfonts
- Open question — will any format supersede WOFF2?
