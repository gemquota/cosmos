# Paint Triggers

## Summary
Property changes that force repainting of pixels. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Color, shadow, and background changes repaint pixels
- Repaint cost scales with painted area, not element count
- Open question — how do GPU-accelerated paints change these costs?
