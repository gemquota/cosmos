# Layout Triggers

## Summary
Property changes that invalidate and recompute layout. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Width, position, and font changes trigger layout
- Layout cascades through affected subtrees and ancestors
- Open question — how do container queries widen layout invalidation?
