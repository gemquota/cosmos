# Variable Fonts

## Summary
Single font files exposing weight, width, and optical axes. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- One variable font spans weight, width, optical, and custom axes
- They cut file count but complicate font-display and subsetting
- Open question — how do variable axes interact with accessibility settings?
