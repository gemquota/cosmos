# Font Subsetting

## Summary
Trimming font files to only the glyphs a site actually uses. A stub in the mykb wiki that frames the concept and the questions to expand into a full article.

## Details
- Subsets keep only glyphs a site uses, often per unicode-range
- Language subsets trade per-page size for request count
- Open question — how do variable fonts complicate subsetting?
