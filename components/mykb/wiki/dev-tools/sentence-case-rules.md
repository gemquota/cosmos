# Sentence Case Rules

## Summary
Sentence case capitalizes only the first word of a title plus proper nouns, the convention used by most technical documentation and this wiki's descriptions.

## Details
- The wiki mixes title case for article titles with sentence case for descriptions, so the rule must state which applies where.
- Automated casing checks are cheap and catch the most common inconsistencies without demanding judgment.
- For mykb, sentence-case rules govern description and tag casing while title-case rules govern headings.
