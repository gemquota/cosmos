# Edit Summaries

## Summary
Edit summaries are the short descriptions attached to each change, telling readers and reviewers what the edit did and why.

## Details
- A good summary makes the recent-changes feed scannable and the history auditable.
- The convention is: state the change, state the reason when it is non-obvious, and reference the flag or proposal when one exists.
- For mykb, edit summaries are required on structural changes and feed the changelog for release-days.
