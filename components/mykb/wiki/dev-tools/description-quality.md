# Description Quality

## Summary
Description quality means the frontmatter description is a single, concrete sentence that says what the article is about and why it matters — not a label and not a thesis.

## Details
- Descriptions are the graph labels: they appear in search results, link tooltips, and graph visualizations, so they must be informative out of context.
- Weak descriptions repeat the title; strong ones add the one fact that distinguishes this concept from its neighbors.
- For mykb, description quality is lint-checkable for length and structure, and human-reviewed for informativeness.
