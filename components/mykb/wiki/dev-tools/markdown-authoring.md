# Markdown Authoring

## Summary
Markdown authoring is the craft of writing documents in a lightweight, readable markup that renders to HTML. It is the lingua franca of docs-as-code, wikis, and this very knowledge base.

## Details
- Dialects differ (CommonMark vs GitHub-flavored); tables, footnotes, and math are non-core extensions.
- Semantic structure — headings, lists, links — makes markdown parseable by agents.
- RSIS3 relevance: every mykb article is a markdown document with strict frontmatter.
