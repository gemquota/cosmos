# Consistent Titles

## Summary
Consistent titles follow one naming scheme across the wiki — same casing rules, same ordering of words, no synonyms for the same concept.

## Details
- Inconsistency fragments the graph: curators and search both fail when one concept is stored under three different names.
- Consistency is maintained at naming time (seed criteria) and repaired via alias and redirect criteria when it slips.
- For mykb, consistent titles make slug-stability possible: names chosen well up front rarely need changing later.
