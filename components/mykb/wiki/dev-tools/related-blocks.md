# Related Blocks

## Summary
The Related block is the standardized closing section listing 4-8 wikilinks to other articles, each annotated with why it is related.

## Details
- Its job is navigation and synthesis: it tells the reader where to go next and shows where this concept sits in the graph.
- Consistent Related blocks make reciprocity checks possible — the same link should appear in the target's block when the relationship is mutual.
- For mykb, the Related block is a frontmatter-adjacent convention enforced by related-link-quality review.
