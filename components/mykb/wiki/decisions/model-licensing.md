# Model Licensing

## Summary
Model licensing sets the legal terms for using a released model: open, research-only, or commercial-restricted.

## Details
- Model licensing sets the legal terms for using a released model: open, research-only, or commercial-restricted.
- License choice shapes ecosystem, liability, and governance.
- Good licenses state scope, redistribution, and attribution clearly.
- RSIS3 relevance: the bundle's own content and tools carry license choices.
