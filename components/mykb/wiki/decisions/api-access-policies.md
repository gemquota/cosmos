# API Access Policies

## Summary
API access policies define who can call a model service, at what rate, for what uses, and with what monitoring.

## Details
- API access policies define who can call a model service, at what rate, for what uses, and with what monitoring.
- Policies balance openness with abuse prevention.
- Enforcement includes keys, quotas, and review.
- RSIS3 relevance: internal tooling APIs have analogous access rules.
