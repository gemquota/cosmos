# Model License Risks

## Summary
Model license risks arise when models, data, or outputs are used in ways their licenses forbid.

## Details
- Model license risks arise when models, data, or outputs are used in ways their licenses forbid.
- Common traps: research-only licenses in production, copyleft training data, and unclear output ownership.
- License compliance requires inventorying every model and dataset in the pipeline.
- RSIS3 relevance: the bundle's tooling choices carry license obligations.
