In Android development the platform ships standard navigation icons, and many design systems define their own arrow glyphs for consistency across screens.

Navigation is the most frequent use of a left arrow. A back button returns the user to the previous screen, a pager control moves to the previous item, and a collapsing panel uses the same glyph rotated to indicate state. Because the meaning is conventional, users expect the arrow to point in the direction of travel: a left arrow means go back, while a right arrow means go forward.
