Matplotlib — a Python plotting library for creating static, animated, and interactive visualizations.

ATP is recorded here as a token whose description points to Matplotlib, the standard Python plotting library. Matplotlib produces publication-quality static charts, animated sequences, and interactive figures, and it underpins much of scientific computing in Python through its pyplot interface. The library renders line plots, scatter plots, histograms, bar charts, and heatmaps, and it composes them into multi-panel figures with a fine-grained object model.
