## Apex

APEX — Apex. A Salesforce programming language or peak performance.

In the most common technical sense, Apex is a strongly typed, object-oriented programming language used on the Salesforce platform. It resembles Java in syntax and runs server-side on Salesforce's multitenant infrastructure, where it is subject to governor limits on CPU time, heap, and query rows. Developers write Apex to implement custom business logic, triggers, batch jobs, REST endpoints, and Lightning components. Queries are written in SOQL, the Salesforce Object Query Language, which is optimized for the platform's relational data model and enforces row-level access rules automatically.

APEX also names Oracle Application Express, a low-code platform for building database-backed web applications, and in everyday usage the word means the highest point of performance. Sessions tagged api, auth, and bash most plausibly involved the Salesforce language, since REST APIs and OAuth-based connected apps are routine parts of Salesforce integration work, and command-line tooling such as the Salesforce CLI pushes metadata and source between environments.

Distinguishing the senses matters when reading session notes: Salesforce Apex involves governance, governor limits, and deployment through metadata APIs, while Oracle APEX involves SQL, PL/SQL, and declarative pages. The page therefore serves as a disambiguation hub for the acronym and should be updated with the specific platform whenever a session makes the reference unambiguous. Either way, authentication and careful API design are the connective tissue between the two readings.

For readers of session logs, the practical rule is to look for platform nouns — Salesforce, governor limits, or SOQL — before choosing the meaning, since those tokens disambiguate instantly.
