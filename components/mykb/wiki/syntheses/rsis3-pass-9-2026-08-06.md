# RSIS3 Pass 9 — Spec Link

## Summary
Pass 9 (spec link) fed SPACE's 326-probe spec data into L2 ideation and the
Guide. A `SpaceSpec` gateway (`components/rsis3/rsis/space_spec.py`) flattens
the exported spec (67 artifacts with value, source series/question,
confidence) and ranks candidate L2 goals whose strings embed
`SPACE spec artifact <id>` — so `python -m rsis run --goal from-space`
sources the goal from a spec artifact and the telemetry trace references it
(the pass's verification chain). The Guide Direction tab now renders a
**live loop & memory state** panel from one shared payload: `scan_guidance()`
gained a `live` section (RSIS3 loop stack from `loops.json`, per-loop
telemetry starts, spec-backed L2 goal traces, recent MyKB syntheses) served
by both the daemon `/api/v2/guidance` and the static `guidance.json`. The
full 5-cycle × L1–L9 batch ran **+5 net starts per loop, 0 errors**, and the
spec-sourced `run` left a durable L2 goal trace.

## Details
- **Spec → goals** — `SpaceSpec.artifacts()` sorts by confidence; each goal
  is `Implement the <id> spec artifact: <value> (SPACE spec artifact <id>,
  series <n>, question <q>)`. Path resolution: `RSIS_SPACE_SPEC` env, else
  `<cosmos>/components/space/exports/recursive-self-improvement-specification.json`.
- **Traceable verification** — `run` cycle 3 of the batch used
  `--goal from-space`; telemetry records an `l2_start` goal referencing
  `spec artifact abstraction_level` (series 1, Q1.1.1), surfaced in the
  Guide's `live.telemetry.spec_traces`.
- **One shared Guide payload** — `scan_live_state()` (stdlib) merges
  rsis3 loop/telemetry reads + MyKB syntheses into `scan_guidance()`, so the
  daemon and the static snapshot agree; the Direction tab renders it with
  graceful empty states when rsis3 data is absent.
- **L3 continued self-consolidating** — cycles 6–10 wrote
  `rsis3-l3-cycle-{6..10}-cross-session-memory-consolidation-2026-08-06.md`
  + 5 `log.md` entries; the pass-8 durable-ordinal fix produced clean
  distinct titles with no suffix collisions.
- **Batch** — 40 executions (5 × `run` with cycle 3 spec-sourced, 5 × each
  one-shot loop), +5 net starts per loop, 0 errors. Telemetry now L1=26,
  L2=26, L3=24, L4=24, L5=28, L6=25, L7=23, L8=23, L9=22; ledger 180 files /
  602 events / 0 malformed.

## Rules going forward
- SPACE spec exports are a first-class ideation source; new goal sources
  keep a machine-greppable marker (`spec artifact <id>`) in the goal string
  for traceability.
- Guide surfaces share one payload — extend `scan_guidance()`/`guidance.json`
  rather than adding parallel ad-hoc lists.
- Cross-component reads stay optional and degrade to empty state.
- Durable sequence numbers for loop-generated notes (pass 8 rule) continue
  to hold.
