# RSIS3 Pass 10 — UX Cohesion

## Summary
Pass 10 (UX cohesion) finished the user-visible surfaces on live data. The
Guide gained a **Models** tab that renders the loop-tuning topology — which
meta loop tunes which parameter stack and at what current values — from the
same guidance payload as the live loop panel. The knowledge graph page
(`okf-graph.html`) stopped embedding stale copies and now **lazy-loads** the
regenerated `graph.json` + `catalog.json`/`index.json`/`log.json` payloads
(5,418 concepts · 36,892 links). Every surface in the unified dashboard and
the wiki was walked in a browser: Overview, Guide Direction/Models/Queue/
Triage tabs, article view with the Graph/Edit/Archive/Delete toolbar, KG
loading, links, and the sidebar — no broken surfaces, and static-hosted API
fallbacks (404 → `guidance.json`) confirmed working.

## Details
- **Models tab** — `gdRenderModels()` in `components/mykb/index.html` reads
  `GUID.liveState.loops[*].params` and renders a card per tuner loop (L4–L9)
  showing `id`, name, tuning target, and each `key = value`; loops with no
  params are skipped and an absent payload renders an empty state. The
  Direction tab's live loop panel shares the same payload, so both stay in
  sync.
- **Per-loop tuning metadata** — `scan_live_state()` (`.wiki-daemon/
  build_stub_audit.py`) now emits `target` + `params` per loop from
  `dashboard/loops.json`, so the Guide renders tuning topology without
  needing the dashboard.
- **KG lazy boot** — `okf-graph.html` fetches `graph.json` + the catalog via
  `okfCatalogFetch()` and then boots; `clusterLayout()` falls back to
  concentric layout when `NODES.length > 1200`; index/log getters handle
  bare-array payloads. Verified live: 5,418 concepts · 36,892 links with
  populated type/area/tag filters.
- **Payload generation refactor** — `build_graph.py` emits
  `graph.json` + `catalog.json` + `index.json` + `log.json` to both the
  static mykb root and `.wiki-daemon/` using the shared
  `frontmatter.parse_frontmatter` helper and skipping hidden dirs. Daemon
  copies are gitignored (consistent with the existing `graph.json` rule);
  static copies are committed.
- **Date-rollover test fix** — the MyKB gateway tests asserted a hard-coded
  2026-08-06 wall clock; they now freeze time with `mock.patch` so the suite
  (57 tests) stays green after the date rolls over.
- **Verification walkthrough** — dashboard Overview / MyKB / SPACE / KG tabs,
  Guide Direction (live loop stack L0–L9, spec goal traces, recent
  syntheses) and Models (L4–L9 tuned params), article view (toolbar +
  type/tags), wiki graph tab (physics completes → "drag to pan"), and
  `okf-graph.html` all render; `check-practices` all PASS, contracts OK
  (0 FAIL), wiki link check 0 unresolved, snapshots `--check` OK.

## Rules going forward
- Guide tuning surfaces render from one payload — extend
  `scan_live_state()` when new tuning dimensions appear instead of adding
  parallel lists.
- KG pages must lazy-load regenerated payloads; never re-embed static
  graph/catalog copies (they go stale and bloat the page).
- Payload generators write both static + daemon copies; keep daemon copies
  gitignored and commit the static ones.
- Tests that assert on wall-clock timestamps must freeze time with a mock,
  not hard-code the current date.
- Static-hosted UI must degrade to `guidance.json`/`stub-review.json` when
  daemon API routes 404 — verified as the normal walkthrough path.
