# Fallback Plans

## Summary
Fallback plans define what happens when a system fails: manual mode, degraded service, or rollback.

## Details
- Fallback plans define what happens when a system fails: manual mode, degraded service, or rollback.
- Good fallbacks are rehearsed, not improvised.
- Fallback quality decides whether incidents become outages.
- RSIS3 relevance: git rollback and re-runs are the bundle's fallback plans.
