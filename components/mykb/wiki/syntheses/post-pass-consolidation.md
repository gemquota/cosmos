# Post-Pass Consolidation

## Summary
Post-pass consolidation is the ritual of closing a work pass: verifying outputs, fixing stragglers, updating indexes and logs, and writing the synthesis that lets the next pass start from a cleaner base. It is the knowledge-work equivalent of memory consolidation.

## Details
- **Steps** — verify all outputs, repair broken links, update stats/logs, snapshot state, and write a synthesis note.
- **Why it matters** — an unconsolidated pass leaves debt that compounds across passes.
- **Verification-first** — consolidation validates what was produced (word counts, frontmatter, link resolution) before declaring success.
- **Link to RSI** — each consolidated pass is a checkpoint the system can roll back to and build on.
- **RSIS3 example** — this pass's own final report and the graph-health checks are its consolidation step.
