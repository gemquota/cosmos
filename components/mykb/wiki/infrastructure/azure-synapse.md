# Azure Synapse Analytics

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Synapse combines dedicated/pool SQL, serverless SQL over data lakes, Apache Spark, and orchestration.
- Dedicated SQL pools are MPP engines with distributions; serverless SQL reads files directly.
- Synapse Link enables near-real-time replication from operational stores like Cosmos DB.
- It competes as Azure's hub for lakehouse and warehouse workloads with tight Microsoft ecosystem integration.
