# Data Governance Frameworks

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Governance covers ownership, classification, access, quality, lifecycle, and usage policy for data assets.
- Frameworks (DAMA-DMBOK, DCAM, custom) define roles, councils, policies, and operating procedures.
- Practical governance starts with a data dictionary, owners, and access reviews; automation scales it.
- Good governance is an enabler: clear owners and contracts speed up safe self-serve analytics.
