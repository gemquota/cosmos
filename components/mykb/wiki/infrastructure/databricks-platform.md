# Databricks Platform

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Databricks runs managed Spark clusters on cloud VMs with Unity Catalog governance and Delta Lake storage.
- The workspace model covers batch, structured streaming, SQL warehouses, notebooks, and MLflow.
- Photonic engine and Delta performance features accelerate lakehouse queries.
- It is the reference implementation of the lakehouse pattern with open APIs on top.
