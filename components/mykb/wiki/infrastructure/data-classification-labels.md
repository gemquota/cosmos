# Data Classification Labels

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Labels like Public, Internal, Confidential, PII drive handling rules.
- Classify at the column and dataset level, inherited downstream.
- Labels feed masking, access, retention, and breach response.
- Automate detection; keep humans accountable for edge cases.
