# Data Mesh vs Data Fabric

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Data mesh: domain-owned data products with federated governance.
- Data fabric: centralized metadata layer automating integration across sources.
- Mesh decentralizes ownership; fabric centralizes automation.
- Both target scale beyond a single central team; start with products or metadata.
