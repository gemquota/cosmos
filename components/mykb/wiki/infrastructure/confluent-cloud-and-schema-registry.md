# Confluent Cloud and Schema Registry

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Confluent Cloud offers managed Kafka, ksqlDB, and connectors with usage-based pricing.
- Schema Registry stores Avro/Protobuf/JSON schemas with compatibility checks.
- Schema evolution policies (backward/forward/full) gate producer/consumer compatibility.
- It is the standard governance layer for Kafka ecosystems, on-prem or cloud.
