# Guardrail Metrics

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- Guardrails are metrics that must not regress while primary metrics improve.
- Examples: latency, error rate, support contacts, engagement quality.
- Ship decisions weigh primary gains against guardrail losses.
- Define guardrail thresholds with stakeholders before experiments.
