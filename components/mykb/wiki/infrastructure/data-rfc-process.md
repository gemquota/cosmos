# Data RFC Process

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- RFCs propose significant changes with context and alternatives.
- Review cycles gather feedback before implementation.
- Number and archive RFCs; decisions become durable history.
- Reserve RFCs for changes with broad blast radius.
