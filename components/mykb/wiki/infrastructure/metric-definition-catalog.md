# Metric Definition Catalog

## Summary

A stub to be expanded into a full article; frames the concept and open questions.

## Details

- A metric catalog records formula, grain, filters, owner, and change history.
- Consistent definitions prevent metric wars between dashboards.
- Semantic layers and dbt metrics operationalize the catalog.
- Version metrics; changing a definition silently breaks comparisons.
