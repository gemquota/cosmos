# Note-Taking Methods

## Summary
Note-taking methods are the structured practices used to capture information so it can be reviewed, connected, and reused later. Their choice shapes how well knowledge survives the move from page to memory — the format determines whether the note is reviewable, linkable, and retrievable, or just a faithful record of what was said.

## Details
- **Major families** — outline (linear hierarchy), visual (mind maps, Cornell layouts), and networked (atomic notes with links, Zettelkasten). Each family optimizes for a different outcome: outlines for structure, visual methods for overview, networked methods for reuse.
- **Fit matters** — lectures favor Cornell's cue column; reading favors margin summaries; long-term knowledge favors linked atomic notes. The mismatch cost is real: taking lecture notes as a mind map produces a great picture of the lecture and a poor study aid for the exam, because the cue-answer retrieval loop is missing.
- **Concrete example** — the same technical talk yields three different artifacts: an outline preserving the speaker's hierarchy, a Cornell page whose cues test the key claims, and three atomic notes (one per mechanism) linked into the wiki. The third artifact keeps working months later; the first two age quickly.
- **Failure modes** — transcription without processing, where the notes are complete and useless (nothing was distilled); method dogma, where the format is followed even when it fights the material; and capture without a review step, which severs the note from the memory the method was supposed to build.
- **Tradeoffs** — every method trades capture speed against retrieval power: fast verbatim capture produces notes you must re-read entirely, while slow structured capture produces notes that answer questions directly. The durable compromise is cheap full capture plus a separate processing pass into atomic, linked notes.
- **Agent relevance** — mykb's wiki is a note-taking method: every page captures one idea with frontmatter and links for later retrieval. The capture hooks automate the cheap part, and the curation pass performs the processing that human methods require as a separate step.
- **RSIS3/mykb relevance** — note-taking choice is an architectural decision for the memory layer: the method determines whether captured knowledge can be connected and resurfaced, which is precisely what the L3 consolidation practice depends on.
