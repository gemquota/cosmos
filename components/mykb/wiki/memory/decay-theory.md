# Decay Theory

## Summary

Decay Theory — Forgetting as the fading of memory traces over time.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Oldest account of forgetting: traces weaken with disuse unless rehearsed.
- Hard to test cleanly because time correlates with interference and context change.
- Modern versions survive in time-based accounts of working-memory loss.
- Complements interference-theory; both shape the forgetting-curve.
