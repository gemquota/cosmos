# Autobiographical Reasoning

## Summary

Autobiographical Reasoning — Drawing connections between life events and the self to derive meaning.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Autobiographical reasoning links specific episodes to stable self-conceptions (e.g., 'that made me resilient').
- Supports identity development and posttraumatic growth when done constructively.
- Can also solidify distorted self-stories if unchecked.
- Core process behind narrative identity and reflective practice.
