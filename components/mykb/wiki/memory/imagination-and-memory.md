# Imagination and Memory

## Summary

Imagination and Memory — Shared cognitive machinery for imagining events and remembering them.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Imagination and memory recruit overlapping hippocampal and default-mode networks.
- Imagining an event can later be mistaken for a memory of it — the imagination inflation effect.
- Imagination also serves episodic future thinking and counterfactual reasoning.
- A key caution for eyewitness and false-memory research.
