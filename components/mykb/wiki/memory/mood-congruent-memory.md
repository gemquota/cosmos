# Mood-Congruent Memory

## Summary

Mood-Congruent Memory — Tendency to recall material whose emotional tone matches current mood.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- People retrieve more positive memories when happy, more negative when sad.
- Effect appears in encoding (mood biases attention) and retrieval (mood biases access).
- Clinical relevance: depressed mood maintains itself partly through easier access to negative memories.
- Pairs with flashbulb-memory as an emotion-memory phenomenon.
