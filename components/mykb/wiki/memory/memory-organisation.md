# Memory Organisation

## Summary
Memory organisation is how a knowledge base arranges its contents — namespaces, types, indexes, links, and retrieval aids — so items are findable when needed. It is the bridge between storing something and being able to use it.

## Details
- **Layers** — physical (directories/files), logical (types, taxonomies), and associative (links, co-occurrence).
- **Patterns** — typed namespaces, stable titles, frontmatter conventions, and index pages that enumerate the collection.
- **Agent relevance** — mykb organizes memory by `type` (concept, synthesis, pulse, decision) plus domains; the temporal engine adds a time axis for retrieval.
