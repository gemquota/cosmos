# Habit vs Goal-Directed Control

## Summary

Habit vs Goal-Directed Control — Dual systems of action: automatic stimulus-response habits vs deliberative goals.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Habits run on stimulus-response associations; goal-directed control uses model-based evaluation.
- With overtraining, behavior shifts from goal-directed to habitual, resistant to outcome change.
- Stress and load bias the system toward habit.
- Modeled computationally as model-free vs model-based reinforcement learning.
