# Encoding-Retrieval Match

## Summary

The encoding-retrieval match principle states that retrieval succeeds when the conditions at recall overlap with the conditions at encoding. Context, cues, and internal state all form part of that match. It matters because it explains both why context-dependent memory works and how to design better retrieval practice. The principle is a design rule: build the retrieval cue into the way the material was learned.

## Details

- **Definition** — Memory is strongest when the cues present during retrieval resemble those present when the memory was encoded.
- **Context dependence** — Environment, mood, and internal state become part of the memory trace, aiding recall when they recur.
- **Cue specificity** — Specific cues trigger specific memories; generic cues retrieve generic or competing information.
- **Transfer-appropriate processing** — Deep overlap between how information is processed at study and at test improves later performance.
- **Practical use** — Studying in varied conditions, with realistic cues, builds memories that survive real-world retrieval.
- **Worked example** — Recalling a fact in the room where it was learned is easier than in a novel setting, until practice varies the cues.
- **Failure modes** — Over-relying on one context, or studying with cues that will not exist at test time, produces brittle memory.
- **Practical relevance** — The principle guides flashcard design: match the prompt to the situation where the knowledge will be used.
- **Cue variation** — Practicing with varied cues builds flexible memories that survive context shifts.
- **Test design** — Exams that mirror study conditions measure learning fairly; mismatched conditions measure context sensitivity.
- **Application** — Skills should be practiced in the environment and format where they will be used.
