# Generation Effect

## Summary

Generation Effect — Producing information oneself improves memory more than reading it.

## Details

- The generation effect is the finding that self-generated information is remembered better than identical information that is merely read. Slamecka and Graf demonstrated it with word fragments ('c-a-? → cat'), and it extends to answers, examples, and summaries.
- Explanations emphasize deeper semantic processing, stronger item-specific encoding, and the effort of producing the response. The effect persists across delays and pairs with the testing effect because both route learning through active production.
- Worked example: completing a sentence 'Anki uses the ___ algorithm' beats reading 'Anki uses the SM-2 algorithm' — the generation attempt encodes the link more strongly.
- Boundary conditions: generation helps most when it is meaningful and does not create long error trials without feedback; generated errors can persist unless corrected.
- mykb relevance: note formats that force generation (closed-book summaries, fill-in questions) apply the effect to knowledge capture.
