# Keyword Method

## Summary

Keyword Method — Vocabulary mnemonic linking a foreign word to a similar-sounding keyword image.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Find a keyword in your language that sounds like the target word, then picture them interacting.
- Example: Spanish 'pato' (duck) → keyword 'pot' → image of a duck in a pot.
- Meta-analyses show it reliably improves immediate and delayed vocabulary recall.
- Works best for concrete, imageable keywords; less useful for abstract terms.
