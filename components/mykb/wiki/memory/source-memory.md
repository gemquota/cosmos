# Source Memory

## Summary

Source Memory — Remembering where, when, and from whom information came.

## Details

- Source memory is memory for the origin of information — who said it, where you read it, when it happened — as distinct from memory for the content. Source monitoring is the set of processes that attribute memories to sources (external event, dream, imagination, another person).
- Source errors drive many real-world failures: misattributing a friend's suggestion as your own, recalling imagined events as real (reality monitoring failures), and the sleeper effect (forgetting the source of a message while keeping its content).
- Worked example: you remember a striking claim but not whether it came from a peer-reviewed paper or a tweet; the source trace is weak even though the content trace is strong — this is why provenance matters.
- Factors: vividness, familiarity, schema-consistency, and delay all shift source attribution; distinctive sources are remembered better than similar ones.
- mykb relevance: provenance fields and citations are source-memory externalized — the wiki records the origin so retrieval does not have to.
