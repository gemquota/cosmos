# Retrieval-Induced Forgetting

## Summary

Retrieval-Induced Forgetting — Retrieving some memories suppressing access to related competing ones.

## Details

- Retrieval-induced forgetting (RIF) is the finding that practicing some items from a category impairs recall of the unpracticed related items. Anderson's retrieval-practice paradigm shows inhibition, not decay: the suppressed items recover when tested with different cues, implicating active inhibitory control.
- Mechanism: retrieving a target requires suppressing competing memories that would interfere; the suppression persists, making competitors harder to retrieve later. This is adaptive — it sharpens access — but it means retrieval is not neutral for the rest of memory.
- Worked example: reviewing 'Europe' capitals and testing France and Germany makes recalling Italy slower in a later test, relative to a baseline category; the suppression is cue-dependent and reversible.
- Boundary conditions: RIF is strongest for related competitors, requires successful retrieval, and transfers across contexts. It raises fairness questions in eyewitness memory (who gets rehearsed biases who is forgotten).
- mykb relevance: retrieval practice schedules should expect RIF among closely linked notes — interleaving and spacing mitigate it.
