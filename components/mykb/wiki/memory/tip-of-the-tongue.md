# Tip-of-the-Tongue State

## Summary

Tip-of-the-Tongue State — Felt near-access to a memory that cannot be fully retrieved.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Strong feeling of imminent recall with partial access: first letter, syllables, meaning.
- Often resolved by retrieval cues, delay, or looking the item up (which fixes it).
- Studied as a retrieval failure with intact semantic activation.
- Metacognitive angle: the feeling is a judgment about memory access, not the memory itself.
