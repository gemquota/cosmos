# Acronym Mnemonics

## Summary

Acronym Mnemonics — First-letter memory aids such as acronyms and acrostics.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Acronyms (e.g., SMART) compress a list into one retrievable word.
- Acrostics use first letters of sentences to encode ordered sequences.
- Cheap and fast, but they add little meaning — recall can fail if the acronym itself is lost.
- Best for short lists where ordering matters and deeper elaboration is impractical.
