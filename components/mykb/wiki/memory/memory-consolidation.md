# Memory Consolidation

## Summary
Memory consolidation is the biological and cognitive process that stabilizes new memories and integrates them with existing knowledge, often during rest and sleep. System consolidation moves memories from hippocampus to cortex over time; synaptic consolidation happens within hours. The metaphor extends directly to knowledge bases: fresh notes need linking and rest before they become durable knowledge.

## Details
- **Synaptic consolidation** — within minutes to hours, protein synthesis stabilizes the synaptic changes encoding a new memory.
- **System consolidation** — over days to years, memories are reorganized and integrated into neocortical networks; sleep replay is a key driver.
- **Worked example** — a new mykb note 'RRF formula' is consolidated by linking it to hybrid-search and bm25 and re-reading it after a delay; without linking, it stays an orphan and is effectively forgotten by retrieval.
- **Interference** — new learning can disrupt recent memories; spacing and sleep reduce interference, which is why repetition schedules matter.
- **Agent analogy** — nightly or weekly consolidation passes (reindex, relink, synthesize) mirror the human process and prevent knowledge decay.
