# Externalization of Knowledge

## Summary

Externalization of Knowledge — Encoding knowledge into durable external artifacts such as notes, docs, and models.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- External memory extends internal recall and frees working-memory capacity.
- Artifacts create provenance, reviewability, and shareability that internal memory lacks.
- Externalization is the core operation of a personal knowledge management system like mykb.
- Quality depends on structure: atomic notes, typed links, and metadata.
