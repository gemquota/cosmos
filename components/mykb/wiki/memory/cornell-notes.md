# Cornell Notes

## Summary
Cornell Notes split each page into a narrow cue column, a wide note area, and a bottom summary band. The cue column doubles as a self-test prompt, turning passive notes into an active-recall device.

## Details
- **Layout** — main notes on the right; questions/keywords on the left; a one-paragraph summary at the bottom.
- **Review loop** — cover the notes, answer the cues, verify; this is active recall embedded in the format.
- **Agent relevance** — a summary band plus cue field maps to mykb's `summary` plus `description` frontmatter: both force distillation at capture time.
