# Literate Programming

## Summary

Literate Programming — Weaving executable code and prose explanations into a single document.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Knuth's idea: programs are written for humans first, with code blocks woven into explanation.
- Tools: Jupyter notebooks, Org-mode babel, and literate Haskell.
- Promotes articulation and reproducibility at the cost of toolchain complexity.
- A model for knowledge artifacts that mix reasoning, code, and results.
