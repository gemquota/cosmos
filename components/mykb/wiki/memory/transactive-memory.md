# Transactive Memory

## Summary

Transactive Memory — Shared system where group members specialize in remembering different domains.

## Details

- Transactive memory is a group-level memory system: members encode, store, and retrieve knowledge in a division of labor, plus a shared directory of who knows what. Wegner's theory explains how couples, teams, and organizations remember more than any member could alone.
- The directory is the key structure: knowing who knows makes retrieval a routing problem. Systems form through communication and role differentiation, and they break down when members leave or the directory goes stale.
- Worked example: a team where Alice owns the API details, Bob the deployment runbook, and Carol the product history — a question routes to the owner; the team's effective memory is the union, not the intersection.
- Design for teams: explicit ownership, documented directories, and redundancy for critical knowledge (bus factor). Digital tools can externalize the directory itself.
- mykb relevance: a wiki with ownership and provenance is transactive memory with the directory written down.
