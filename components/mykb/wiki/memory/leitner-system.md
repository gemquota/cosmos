# Leitner System

## Summary

Leitner System — Box-based spaced repetition using error-driven movement between review boxes.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Cards live in boxes; a correct answer promotes a card up, a wrong answer demotes it to box one.
- Each box is reviewed at a different interval, giving a simple error-driven scheduler.
- Easy to implement physically (paper boxes) or digitally, and a good mental model for SM-2/FSRS.
- Trade-off: coarse intervals compared with per-card algorithms like FSRS.
