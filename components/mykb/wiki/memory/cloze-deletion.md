# Cloze Deletion

## Summary

Cloze deletion is a flashcard format where key parts of a sentence are blanked so the learner must supply them from context. It turns notes into recall prompts with minimal effort. It matters because it is the highest-yield card format for language, definitions, and fact learning. Cloze cards convert passive notes into active recall tasks at almost no authoring cost.

## Details

- **Definition** — A cloze card presents a sentence with one or more gaps; the learner's task is to recall the missing text.
- **Context preservation** — Keeping the full sentence preserves meaning and retrieval cues, unlike bare question-answer pairs.
- **Multiple deletions** — Several cards can be generated from one sentence, each testing a different component.
- **Prompt quality** — Gaps should test one idea each; deleting too much produces ambiguous prompts.
- **Worked example** — "The {capital} of France is {Paris}" becomes two cards, each blanking one fact.
- **Failure modes** — Overlapping deletions that leak answers, gaps that are guessable from grammar, and copying without understanding.
- **Practical relevance** — Cloze fits naturally into incremental reading and spaced-repetition workflows.
- **Minimum information** — Each gap tests a single fact; compound deletions create ambiguous prompts.
- **Gap style** — Blank formats vary from full words to numbered hints, affecting difficulty and recall cue quality.
- **Generation** — Automated cloze generation from notes accelerates card creation but needs review for clarity.
- **Review hygiene** — Cloze cards should be reviewed with the answer hidden and recalled before revealing, or they become recognition tasks.
