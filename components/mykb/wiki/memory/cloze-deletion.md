# Cloze Deletion

## Summary

Cloze Deletion — Flashcard type where key parts of a sentence are blanked for recall.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Cloze cards test recognition-in-context: fill in the blank from surrounding sentence.
- Easy to mass-produce from texts, which tempts shallow, fragmented cards.
