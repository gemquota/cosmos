# Encoding Specificity

## Summary

Encoding Specificity — Tulving's principle: retrieval succeeds when cues match encoding conditions.

## Details

- Encoding specificity (Tulving) states that what is stored includes the context and cues present at encoding, and retrieval succeeds when the test reinstates those cues. Memory is not a store of context-free traces; it is a record of cue-trace associations.
- Evidence: recognition failure of recallable words (words free-recalled but not recognized), context-dependent memory effects, and the superiority of identical study-test cues. The principle explains why transfer-appropriate processing works and why reinstating study context helps.
- Worked example: a fact learned while studying in a café is recalled better when tested in a café-like context or with the same mnemonic cue; changing both environment and cue drops retrieval sharply.
- Implications: study in varied contexts to build multiple retrieval routes; test in the format you will need; use distinctive cues deliberately.
- mykb relevance: context-dependent-memory and reinstatement-of-context entries apply the principle to knowledge retrieval.
