# Motor Learning

## Summary
Motor learning is the process of acquiring movement skills — from typing to sports — through practice, feedback, and consolidation. It progresses from slow, deliberate control to fast, automatic execution. Principles like spacing, variability, and augmented feedback transfer to all skill learning.

## Details
- **Stages** — cognitive, associative, autonomous.
- **Key principles** — practice distribution and feedback schedules.
- **In mykb** — skill notes capture drills and error patterns.
