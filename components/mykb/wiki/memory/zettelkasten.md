# Zettelkasten

## Summary
Zettelkasten (German for 'slip box') is a method of keeping permanent, atomic notes that are densely linked rather than filed by topic. Ideas emerge from the network instead of from a fixed outline. Modern tools like Obsidian and Logseq implement it digitally, and mykb's wiki is structurally a networked slip box.

## Details
- **Core rules** — one idea per note; write in your own words; link every note to context; number for identity (modern tools use IDs instead).
- **Why it works** — links create serendipity: retrieval follows the network, and new notes attach to old ones, compounding over time.
- **Worked example** — a note 'spaced repetition beats cramming' links to 'memory retrieval curves' and 'active recall'; later a synthesis about RSIS3 review scheduling emerges by following those links.
- **Contrast with folders** — hierarchies impose one place per idea; Zettelkasten lets an idea live once and be reached from many paths.
- **Agent relevance** — RSIS3 can traverse the same backlink graph to find context for a pulse, mirroring how a human follows the slip box.
