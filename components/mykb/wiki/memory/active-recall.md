# Active Recall

## Summary
Active recall means testing yourself — retrieving an answer from memory — rather than rereading the source. It is the core of the testing effect: the act of retrieval strengthens the memory itself. Flashcard systems, Cornell notes, and self-quizzing all operationalize it, and it pairs naturally with spaced repetition.

## Details
- **Testing effect** — attempted retrieval, even when it fails, produces better long-term retention than restudy; failure with feedback beats passive rereading.
- **Formats** — flashcards (question then answer), closed-book summaries, practice problems, and Cornell-note cue columns.
- **Worked example** — before opening a wiki page on HNSW, try to write down how it differs from IVF; the effort makes the later reading stick.
- **Agent relevance** — RSIS3's L3 reflection (recalling prior pulses before planning) is an active-recall pattern: retrieving past outcomes before acting improves subsequent decisions.
- **Pairing** — active recall supplies the retrieval events that spaced-repetition schedulers space out.
