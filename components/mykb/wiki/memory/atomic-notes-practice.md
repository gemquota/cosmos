# Atomic Notes Practice

## Summary

Atomic Notes Practice — Writing one idea per note to keep a knowledge graph composable.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Atomicity means a note has a single focus and a clear title.
- Small notes link more cleanly and survive reorganization.
- Trade-off: over-splitting fragments context; grain size is a judgment call.
- Foundational to zettelkasten and evergreen systems.
