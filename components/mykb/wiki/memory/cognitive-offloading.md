# Cognitive Offloading

## Summary

Cognitive Offloading — Using the environment and tools to reduce internal cognitive demands.

## Details

- Cognitive offloading is delegating memory, computation, or planning to the environment — notes, calculators, calendars, and external representations. It frees limited working memory and attention for higher-order reasoning, and is a defining feature of human tool use.
- Research shows people offload strategically: when a task strains memory, they write more; reminders and external stores improve performance but can create dependence (the 'Google effect' — remembering where information is stored rather than the content).
- Worked example: a knowledge worker keeps a task list in a tool because tracking it mentally degrades the actual work; the list is not laziness, it is load management.
- Offloading is rational but has costs: externalization can weaken internal memory for the details, and tools fail or go stale. Balanced design keeps the external store synchronized and retrievable.
- mykb relevance: the wiki is cognitive offloading at scale — provenance, links, and search make the external store the primary memory.
