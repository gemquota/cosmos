# Dual Coding Theory

## Summary

Dual Coding Theory — Paivio's account of memory through separate verbal and imagery systems.

## Details

- Dual coding theory (Paivio) proposes two interconnected systems: a verbal system for language and a nonverbal (imagery) system for objects and scenes. Information encoded in both systems is remembered better than information in one, because either system can cue the other at retrieval.
- Concrete words (dog, apple) are dually coded automatically; abstract words (justice, truth) lean on verbal coding alone, which is one reason concrete material is easier to learn. The imagery advantage is strongest for paired-associate and vocabulary learning.
- Worked example: learning the Spanish word 'pato' via a picture of a duck in a pot (keyword method) engages both systems and beats rote translation.
- Applications include the keyword method, visual note-taking, concept maps, and multimedia design. The theory complements encoding-specificity: dually coded items have more retrieval routes.
- mykb relevance: attaching diagrams and examples to notes is dual coding — the same concept gets two encodings and two access paths.
