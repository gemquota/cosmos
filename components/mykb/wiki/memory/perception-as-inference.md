# Perception as Inference

## Summary
Perception as inference holds that the brain infers the world from ambiguous cues using prior knowledge — perception is a hypothesis, not a photograph. Illusions reveal the inferences. The view underpins modern Bayesian and predictive accounts of perception.

## Details
- **Helmholtz** — unconscious inference from sensation to object.
- **Evidence** — illusions and context effects show inference.
- **In mykb** — record observations as hypotheses with confidence.
