# Prospective Memory

## Summary

Prospective Memory — Remembering to perform intended actions in the future.

## Details

- Prospective memory is remembering to do something later — take the medication, send the email, attend the meeting. It contrasts with retrospective memory (remembering the past) and is notoriously fragile: intentions are easy to form and easy to forget when the moment arrives.
- Key distinction: event-based tasks (cue triggers the action — post the letter when you pass the mailbox) versus time-based tasks (act at a time — call at 3pm). Event-based tasks fail when cues are subtle; time-based tasks demand monitoring.
- Worked example: you intend to reply to an email; hours later, without a reminder, the intention is gone — prospective memory failed not because you forgot the content, but because no cue reinstated the intention at the right moment.
- Improvements: implementation intentions (if-then plans), external cues and calendars, and rehearsal of the cue-action link. Prospective memory is a major use case for cognitive offloading.
- mykb relevance: task lists and reminders in the wiki are prospective-memory prosthetics — the external store holds intentions until their cue fires.
