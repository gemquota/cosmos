# Zettelkasten Method

## Summary

Zettelkasten Method — Slip-box note system of atomic notes linked into a web of thought.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Value comes from the link structure: notes are nodes, writing happens by assembling existing notes.
