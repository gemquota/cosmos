# Predictive Coding

## Summary
Predictive coding is the computational theory that cortical areas predict their inputs, send predictions downward, and update with the error signals that flow upward. It explains surround suppression, repetition suppression, and illusion phenomena. It is the leading mechanistic implementation of predictive processing.

## Details
- **Architecture** — prediction units and error units in hierarchies.
- **Evidence** — neural responses track prediction errors.
- **In mykb** — frame anomalies as prediction errors to investigate.
