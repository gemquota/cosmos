# Proactive Interference

## Summary

Proactive Interference — Older memories impair retrieval of newer, similar material.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Classic paradigm: learning list A impairs later recall of list B when items overlap.
- Explains why learning similar topics back-to-back is harder than interleaving distinct ones.
- Release from proactive interference occurs when material changes category.
- Motivates interleaved-practice and spaced review.
