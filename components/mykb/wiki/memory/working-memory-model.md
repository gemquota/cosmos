# Working Memory Model

## Summary

Working Memory Model — Baddeley's multicomponent account of the small capacity system that holds and manipulates information online.

## Details

- Working memory is the limited-capacity workspace for holding and manipulating information during cognition. Baddeley and Hitch's model splits it into a central executive plus three stores: the phonological loop (verbal rehearsal), the visuospatial sketchpad (visual and spatial imagery), and the episodic buffer (binding across modalities and long-term memory).
- The central executive controls attention, task switching, and the allocation of the slave systems. Capacity is roughly four chunks; measured by spans, complex spans, and n-back tasks.
- Worked example: remembering a phone number uses the phonological loop via subvocal rehearsal, while navigating a route uses the sketchpad; planning a chess move binds both through the episodic buffer.
- Cognitive load theory builds directly on this model: instructional design should not overload the executive or the stores. Working memory capacity predicts fluid intelligence and learning speed, so managing it is central to effective study and to agent system design.
- mykb relevance: an agent's context window behaves like a working memory — finite, interference-prone, and best managed by offloading to long-term stores and notes.
