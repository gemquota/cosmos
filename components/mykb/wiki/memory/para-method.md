# PARA Method

## Summary
PARA files everything into four top-level buckets — Projects, Areas, Resources, and Archives — based on the actionability of each item. It is designed to keep knowledge near the work that uses it.

## Details
- **Buckets** — Projects (active, time-bound), Areas (ongoing responsibilities), Resources (topical references), Archives (inactive everything).
- **Principle** — organize by actionability, not topic; a note lives where it is most likely to be needed.
- **Agent relevance** — an agent's memory could use the same triage: active goal context in Projects, standing knowledge in Resources, old pulses in Archives.
