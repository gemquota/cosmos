# Memory Updating

## Summary

Memory Updating — Revising stored memories when new evidence arrives.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Working-memory updating is the online refresh of current contents; episodic updating revises stored episodes.
- Reconsolidation provides a cellular route for targeted revision.
- Healthy systems balance stability (keep true memories) and plasticity (correct stale ones).
- mykb relevance: knowledge bases face the same stability-plasticity tension as memories.
