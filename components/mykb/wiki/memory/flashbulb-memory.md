# Flashbulb Memory

## Summary

Flashbulb Memory — Vivid, detailed recollections of learning about shocking public events.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- People believe these memories are photographic, but research shows they decay like other memories.
- Confidence stays high while accuracy drops — a vividness-accuracy dissociation.
- Now understood as ordinary autobiographical memory boosted by emotion, rehearsal, and novelty.
- Useful caution for source-memory and misinformation research.
