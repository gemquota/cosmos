# Matrix Notes

## Summary

Matrix Notes — Note-taking in a table with topics as rows and aspects as columns.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Matrix structure forces comparison across items, prompting relational processing.
- Useful for lectures or sources with repeated dimensions (theories × criteria).
- Tables become review aids and raw material for concept maps.
- Trade-off: rigid columns can distort material that does not fit the grid.
