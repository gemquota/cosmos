# Spaced Memorization

## Summary

Spaced memorization applies spaced-repetition scheduling to deliberate memorization: selecting material, scheduling reviews, and measuring retention. It converts forgetting from a failure into a plan. It matters because durable memory is built by timing, not by repetition volume. For knowledge systems, the same logic suggests scheduling re-verification of facts, not just human reviews.

## Details

- **Definition** — Spaced memorization is intentional learning where review is scheduled at expanding intervals to counteract forgetting.
- **Contrast with incidental learning** — Unlike passive exposure, spaced memorization selects items, schedules practice, and tracks retention.
- **Scheduling** — Intervals grow after successful recalls and shrink after failures, adapting to each item's difficulty.
- **Retrieval practice** — The act of recalling strengthens memory more than re-reading, so reviews are tests, not repetitions.
- **Item granularity** — Scheduling works best on stable, atomic items; vague or compound material resists clean scheduling.
- **Worked example** — A learner reviews a new term the next day, then three days later, then a week later, extending intervals on success.
- **Failure modes** — Reviewing by calendar instead of performance, cramming, and scheduling compound items produce poor retention.
- **Practical relevance** — For knowledge systems, the same scheduling logic can govern when facts get re-verified or re-consolidated.
- **Algorithm choice** — Interval algorithms range from simple multipliers to adaptive models that estimate item difficulty.
- **Motivation** — Spacing works only if reviews happen; habit and low-friction review sessions sustain the schedule.
- **Measurement** — Retention curves over items reveal which material needs restructuring rather than more reviews.
- **Review hygiene** — Reviewing in the same fixed environment can create context dependence; varying time and place strengthens transfer.
