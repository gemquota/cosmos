# False Memory Formation

## Summary

False Memory Formation — Remembering events that did not happen, or differently than they did.

## Details

- False memories are recollections of events that never occurred, or of details that differ from reality. They arise from the same constructive machinery as true memories: imagination, suggestion, schema-based filling-in, and source-monitoring failures combine to produce confident, detailed fabrications.
- Landmark demonstrations: Loftus's lost-in-the-mall studies (plausible implanted memories), Deese-Roediger-McDermott lists (false recall of non-presented associates), and imagination inflation (imagining raises belief that it happened).
- Worked example: asking participants to imagine a childhood event repeatedly leads a substantial minority to later describe it as genuinely remembered, with detail and emotion — the memory feels real because it is constructed from real components.
- Consequences: eyewitness testimony, therapy recall, and legal evidence are all vulnerable; suggestive questioning and repeated imagination amplify the risk.
