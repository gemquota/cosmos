# Memory and Identity

## Summary

Memory and Identity — How autobiographical memory constitutes the sense of a continuous self.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Personal identity depends on being able to narrate a coherent life story.
- Amnesia disrupts identity when episodic continuity is lost, even if traits remain.
- Memory selection (what we keep and tell) actively shapes who we are.
- Relates to narrative identity and autobiographical reasoning.
