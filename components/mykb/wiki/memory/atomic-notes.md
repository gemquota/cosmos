# Atomic Notes

## Summary
An atomic note holds a single idea, claim, or question — nothing more. Atomicity makes notes uniquely addressable and linkable, so many larger documents can reuse the same small note without duplication.

## Details
- **Rule of one** — one note, one idea; split a long page into several atomic notes when topics diverge.
- **Payoff** — links are precise, deduplication is easy, and syntheses compose atomic notes like building blocks.
- **Agent relevance** — mykb's concept pages are atomic units; entity extraction from sessions produces atomic candidates automatically.
