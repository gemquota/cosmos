# Working Memory Capacity

## Summary

Working Memory Capacity — The individual limit on information that can be held and processed at once.

## Details

- Working memory capacity (WMC) is the amount of information a person can hold and manipulate simultaneously. Miller's 'magical number seven' framed short-term span; modern estimates for working memory proper are around four chunks (Cowan), with substantial individual differences.
- Measurement: complex span tasks (remember items while processing — e.g., solve sums while recalling letters) predict reading comprehension, reasoning, and fluid intelligence better than simple span. WMC is partly heritable but trainable within limits, with transfer remaining contested.
- Worked example: holding a multi-step instruction while executing it — people with higher WMC maintain more steps, follow instructions better, and resist distraction; load-reducing tools (notes, checklists) equalize the field.
- Consequences: cognitive load theory designs instruction to respect WMC; anxiety and fatigue consume capacity.
- mykb relevance: chunking-and-encoding and cognitive-load-theory entries treat WMC as the resource knowledge design must budget.
