# Memory Schema Effects

## Summary

Memory Schema Effects — How prior knowledge structures bias what is encoded and recalled.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Schemas fill in missing details, aiding gist recall but causing schema-consistent distortions.
- Bartlett's classic war-of-the-ghosts work showed systematic transformation toward familiar schemas.
- Schema-congruent material is recalled better; incongruent salient items can stand out.
- Links to false-memory formation and to top-down processing.
