# Bottom-Up Processing

## Summary
Bottom-up processing builds perception from the features of incoming stimuli — edges, tones, and colors — before knowledge refines it. It dominates when stimuli are novel or degraded contexts are absent. Perception normally blends bottom-up data with top-down priors.

## Details
- **Features** — stimulus-driven, fast, and automatic.
- **Role** — anchors perception to the world; prevents hallucination.
- **In mykb** — capture raw observations separately from interpretations.
