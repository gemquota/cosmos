# Odor-Cued Memory

## Summary

Odor-Cued Memory — Scents acting as powerful cues for autobiographical recall.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Odors can trigger vivid, emotional autobiographical memories (the Proust phenomenon)
- Olfactory cues are often more emotional but not necessarily more accurate than other cues.
