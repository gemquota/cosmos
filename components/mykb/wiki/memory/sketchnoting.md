# Sketchnoting

## Summary

Sketchnoting — Live visual note-taking combining text, icons, and layout.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Sketchnotes blend words and drawings to capture talks and meetings in real time.
- Success depends on listening-plus-encoding, not artistic skill.
- Layout conveys hierarchy and flow that linear text flattens.
- Pairs with visual-note-taking and dual-coding rationale.
