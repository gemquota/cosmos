# Progressive Summarization

## Summary
Progressive summarization adds layers of emphasis to a note over time — bold the best lines, then highlight the best of the bold, then write a one-line summary. Each pass makes the note faster to scan and easier to resurface in future contexts.

## Details
- **Layers** — raw text → bold key passages → highlight the best → executive summary; stop when the note serves its purpose.
- **Why it works** — effort is deferred: you only compress what turns out to matter, and the compression itself is retrieval practice.
- **Agent relevance** — LLM summarization can propose layers, but the compression choices (what to keep) stay with the curator.
