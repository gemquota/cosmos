# Second Brain Method

## Summary

Second Brain Method — Building an external knowledge system (capture, organize, distill, express).
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Fortescue's PARA/Capture-Organize-Distill-Express framing treats notes as an external working memory.
- Second brain systems prioritize actionability and project alignment over encyclopedic coverage.
- Criticism: tools alone do not create understanding; retrieval practice and review still matter.
- mykb is a second brain with provenance and graph tooling added.
