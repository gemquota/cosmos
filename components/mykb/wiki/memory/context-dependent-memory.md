# Context-Dependent Memory

## Summary

Context-Dependent Memory — Better recall when the environment matches the encoding environment.

## Details

- Context-dependent memory is the finding that retrieval improves when the external context matches encoding — same room, same music, same smells. Godden & Baddeley's classic study had divers learn words either underwater or on land; recall was best when study and test environments matched.
- The effect is cue-based: contextual features get bound into the trace and act as retrieval cues. It is robust for free recall, weaker for recognition, and strongest when contexts are distinctive.
- Worked example: students who study for an exam in the exam room (or a similar quiet setting) recall more than students who study in noisy, distinct environments and test elsewhere.
- Applications: study-environment consistency for high-stakes tests, and environmental reinstatement as a memory aid. The same logic underlies state-dependent memory for internal states.
- mykb relevance: reinstatement-of-context and encoding-specificity entries extend the principle to knowledge retrieval systems.
