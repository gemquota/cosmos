# Conceptual Change

## Summary

Conceptual Change — Deep restructuring of concepts rather than mere accretion of facts.

## Details

- Conceptual change is the transformation of a learner's core concepts — for example, replacing a folk theory of motion with Newtonian mechanics. It contrasts with accretion, where new facts fit existing structures; change requires the old framework to be revised or abandoned.
- Research shows naive conceptions are coherent, functional, and stubborn: they resist instruction because they explain everyday experience well. Effective change requires confrontation with anomalies, intelligible alternatives, and motivation to revise.
- Worked example: a student believes a heavier object falls faster; dropping a feather and a hammer on the Moon (or a well-designed demonstration) creates an anomaly — but the concept changes only when Newtonian explanation becomes intelligible and plausible.
- Pedagogical implications: elicit prior conceptions, create conceptual conflict, build the new model explicitly, and support transfer. Knowledge integration frameworks track how fragmented ideas cohere over time.
