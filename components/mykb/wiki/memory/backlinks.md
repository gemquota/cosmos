# Backlinks

## Summary
Backlinks are the set of pages that link to a given page. They turn a flat pile of notes into a navigable network and surface unexpected connections, which is why Obsidian and Logseq make them a core view.

## Details
- **Mechanics** — the wiki index inverts the link table: for every target, list all sources.
- **Value** — discover context (who discusses this concept?), find orphans (zero backlinks = unintegrated), and grow links during review.
- **Agent relevance** — mykb's backlink engine already traverses incoming links; RSIS3 uses them to find related memories during planning.
