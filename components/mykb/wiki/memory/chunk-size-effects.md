# Chunk Size Effects

## Summary

Chunk Size Effects — How the size and structure of chunks shape working-memory capacity.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Working memory holds roughly 4 chunks, but chunks can be arbitrarily large with expertise.
- Chunk size depends on prior knowledge: a chess position is one chunk for a master, many for a novice.
- Bigger, well-structured chunks improve capacity but can reduce flexibility of recombination.
- Links to chunking-and-encoding and expertise research in chess.
