# Constructive Episodic Simulation

## Summary

Constructive Episodic Simulation — Theory that memory recombines episodic details to simulate the future.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Schacter & Addis: episodic memory is constructive, flexibly recombining stored details.
- The same constructive machinery builds remembered pasts and imagined futures.
- Explains memory errors as a byproduct of flexibility rather than pure storage failure.
- Frames memory as forward-looking: it exists to simulate and predict.
