# Reconsolidation

## Summary

Reconsolidation — Retrieved memories becoming labile and needing restabilization.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- When a memory is reactivated, it enters a brief unstable window before being re-stored.
- During that window it can be updated, weakened, or strengthened — the basis of memory-updating.
- Research uses reminders + pharmacological or behavioral interference to demonstrate the window.
- Implications for therapy (fear memory updating) and for belief-updating systems.
