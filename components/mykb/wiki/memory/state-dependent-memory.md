# State-Dependent Memory

## Summary

State-Dependent Memory — Recall influenced by matching internal physiological or emotional states.

## Details

- State-dependent memory is the analogue of context dependence for internal states: retrieval improves when the learner's internal state at test matches the state at encoding. Demonstrated with mood (happy-learned material recalled better when happy) and with drug states in classic pharmacological studies.
- The effect is smaller and more variable than environmental context effects, and it is entangled with mood-congruent processing — mood biases what is encoded and retrieved, not just cueing.
- Worked example: material studied while anxious is recalled slightly better during later anxiety; more practically, mood-congruent memory means negative moods preferentially resurface negative memories.
- Implications: manage mood before high-stakes retrieval, and treat emotional state as part of the encoding context.
