# Peg System

## Summary
The peg system is a mnemonic that attaches list items to fixed number-word pegs: each number maps to a memorable word, and the learner visualizes each to-be-remembered item interacting with its peg's image. Because the pegs are fixed and ordered, retrieval is fast — the peg order supplies the list order without any additional mnemonic effort.

## Details
- **Mechanics** — each number 1-10 (or more) maps to a rhyming or shape-based peg word; one classic English set is one-bun, two-shoe, three-tree, four-door, five-hive, six-sticks, seven-heaven, eight-gate, nine-wine, ten-hen. To memorize a list, visualize each item interacting with its peg image — for the third item, picture it tangled in a tree.
- **Why it works** — the peg is a pre-learned, fixed retrieval scaffold: the number is never forgotten because the peg word is over-learned, and the image interaction provides the dual-coded association. Retrieval is fast because the peg order is fixed — recalling item N means recalling the N-th peg, not searching the list.
- **Concrete example** — memorizing a ten-step deploy checklist: the first step (backup) is pictured as a backup tape around a bun, the second (migrate) as a shoe running a migration, and so on; during the deploy, walking pegs 1-10 reproduces the steps in order with no omissions.
- **Failure modes** — weak imagery, where the item-peg interaction is not vivid enough to be distinctive; peg interference, where the same peg set is reused for many lists and the images blur together; and the technique's limit at small numbers — most peg sets scale to 20-100 pegs, but beyond that the scaffold itself becomes a memorization burden.
- **Tradeoffs** — excellent for ordered lists and numbered material (steps, ranks, years), where retrieval speed and order preservation matter; weak for conceptual material, since pegs encode sequence, not meaning. The number-shape system is the visual variant for those who prefer shapes to rhymes.
- **Operational practice** — over-learn the peg set until it is automatic, keep one peg set per domain to reduce interference, make the interactions bizarre and interactive, and pair peg recall with spaced repetition so the list is actually rehearsed.
- **RSIS3/mykb relevance** — the peg system is the canonical answer to the serial-position problem in memory; for the knowledge base it models how fixed, over-learned scaffolds can make ordered retrieval reliable — the same reason stable indexes and numbered conventions work in wikis.
