# Peg System

## Summary

Peg System — Mnemonic that attaches list items to fixed number-word pegs.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Each number 1-10 (or more) maps to a rhyming or shape-based peg word.
- To memorize a list, visualize each item interacting with its peg image.
- Excellent for ordered lists; retrieval is fast because the peg order is fixed.
- Related to the number-shape system, which uses visual shapes instead of rhymes.
