# Obsidian

## Summary
Obsidian is a local-first markdown note-taking app built around `wikilinks`, a backlink panel, and a graph view. It popularized the linked-notes workflow that Zettelkasten methods need, with plain files that stay portable.

## Details
- **Core** — files are plain markdown on disk; links, backlinks, and graph views derive from the text itself.
- **Ecosystem** — plugins add spaced repetition, databases, and publishing; vaults sync over any file-sync tool.
- **Agent relevance** — mykb's wiki is Obsidian-compatible by design: RSIS3 writes plain markdown with wikilinks and frontmatter that Obsidian renders.
