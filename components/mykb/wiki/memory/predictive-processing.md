# Predictive Processing

## Summary
Predictive processing describes the brain as a prediction machine that constantly anticipates input and updates models when predictions fail. Perception, action, and learning all run on prediction error minimization. It unifies perception, cognition, and motor control under one principle.

## Details
- **Mechanism** — hierarchical prediction and error correction.
- **Scope** — perception, action selection, and learning.
- **In mykb** — treat surprises as model-update signals.
