# Long-Term Memory Architecture

## Summary

Long-Term Memory Architecture — How durable knowledge is organized into declarative and nondeclarative systems.

## Details

- Long-term memory is the durable store whose contents survive minutes to decades. Its broadest split is declarative (explicit, verbalizable) versus nondeclarative (implicit, expressed through performance).
- Declarative memory divides into episodic (personal events with time and place) and semantic (general facts). Nondeclarative covers procedural skills, priming, conditioning, and habit learning. The hippocampus supports declarative encoding; the neocortex stores the traces; the striatum and cerebellum support procedural learning.
- Comparison: episodic memory answers 'what happened to me when', semantic answers 'what is true', and procedural answers 'how do I do it'. They dissociate in amnesia: patients can lose episodic recall while retaining skills and vocabulary.
- Encoding, consolidation, and retrieval routes differ per system, so study strategies must too: retrieval practice serves declarative knowledge, while distributed motor practice serves procedural skill.
- mykb relevance: a knowledge base is primarily semantic long-term memory, with episodes and reflections supplying the episodic channel and scripts/habits the procedural one.
