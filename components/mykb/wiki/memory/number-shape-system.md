# Number Shape System

## Summary

Number Shape System — Mnemonic mapping digits to visual shapes for remembering numbers.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Each digit 0-9 maps to an object its shape resembles (e.g., 1 = candle).
- Numbers become image sequences that can be placed in a memory palace.
- Pairs naturally with the peg system for longer numeric strings.
- Good for PINs, phone numbers, and dates.
