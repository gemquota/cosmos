# Top-Down Processing

## Summary
Top-down processing uses knowledge, expectations, and context to interpret sensory input, making perception fast and meaningful — and fallible. It is the counterpart to bottom-up data flow and is prominent in reading, object recognition, and ambiguous stimuli.

## Details
- **Examples** — reading misspelled words, seeing faces in clouds.
- **Cost** — illusions and expectation-driven errors.
- **In mykb** — label assumptions when interpreting data.
