# Memory Palace

## Summary

Memory Palace — Method of loci: placing to-be-remembered items along a familiar spatial route.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Walk a familiar location mentally, placing vivid images of each item at distinct stations.
- Recall by taking the same route and 'seeing' what was placed at each station.
- Works because spatial memory is robust and provides an ordered scaffold.
- Elaborate palaces with multiple routes support thousands of items; requires practice.
