# Cognitive Load Theory

## Summary

Cognitive Load Theory — Instructional theory built on working-memory limits and schema-based long-term memory.

## Details

- Cognitive load theory (Sweller) treats learning as schema acquisition in long-term memory, gated by a working memory with severe capacity limits. It distinguishes intrinsic load (imposed by the material's complexity), extraneous load (imposed by poor presentation), and germane load (devoted to schema construction).
- Design principles follow: worked examples reduce extraneous load for novices, split-attention effects argue for integrated text-and-diagram, and redundancy warns against repeating the same information twice. The expertise reversal effect notes that supports that help novices hinder experts.
- Worked example: teaching a complex diagram — labeling parts directly on the diagram (integrated) beats describing them in a caption below (split attention), freeing working memory for understanding.
- Modern extensions (e.g., cognitive load in multimedia, self-management of load) apply the same accounting to any environment that presents information: documentation, dashboards, and agent context windows.
- mykb relevance: note structure and link density are a load-management problem; atomic notes reduce extraneous load at read time.
