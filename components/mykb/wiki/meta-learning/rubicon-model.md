# Rubicon Model

## Summary

Rubicon Model — Heckhausen's phase model separating deliberation from volitional implementation.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Four phases: predecisional deliberation, preactional planning, actional implementation, postactional evaluation.
- Crossing the rubicon = committing to a goal and switching to implementation mindset.
- Explains why post-commitment information is processed differently.
- Useful for designing decision and planning systems.
