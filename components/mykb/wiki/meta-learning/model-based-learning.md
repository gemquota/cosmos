# Model-Based Learning

## Summary

Model-Based Learning — Learning through an explicit internal model of the environment.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Model-based agents build and update a world model, enabling planning and flexible transfer.
- Computationally expensive but sample-efficient and robust to change.
- In humans, maps the goal-directed control system.
- Contrast with model-free learning; hybrid accounts mix both.
