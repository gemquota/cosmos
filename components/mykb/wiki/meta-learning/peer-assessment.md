# Peer Assessment

## Summary

Peer Assessment — Learners evaluating each other's work against criteria.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Peer assessment provides scalable feedback and builds evaluative judgment.
- Reliability varies; rubrics and training improve agreement.
- Givers often learn as much as receivers.
- Common in writing, design, and project-based learning.
