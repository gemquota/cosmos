# Subjective Task Value

## Summary

Subjective task value is how much a task matters to a person, encompassing intrinsic interest, utility for future goals, attainment value for identity, and perceived cost. It is the "value" half of expectancy-value theory, working alongside success expectations to drive motivation. Subjective task value matters because it explains why people choose, persist in, and enjoy some activities over others regardless of ability.

## Details

- **Definition** — subjective task value is the personal significance attached to a task, distinct from objective importance and from ability beliefs.
- **Intrinsic value** — the enjoyment and interest a task itself provides; high intrinsic value sustains engagement without external rewards.
- **Utility value** — the usefulness of a task for future goals, such as career plans; even uninteresting tasks can be valued for their instrumentality.
- **Attainment value** — the importance of doing well for one's identity; tasks that affirm who one is carry high attainment value.
- **Cost** — the perceived price of engagement, including effort, time, lost alternatives, and emotional strain; cost subtracts from total value.
- **Development** — values are shaped by experience, socialization, and feedback, and they change across development and context.
- **Worked example** — a student finds statistics boring (low intrinsic value) but takes the course because it is required for a desired career (high utility value).
- **Failure modes** — interventions that raise value without addressing cost can fail; high cost can nullify otherwise high value.
- **Practical relevance** — relevance interventions, authentic tasks, and cost reduction make learning environments more motivating.
- **Measurement** — validated scales assess the value facets separately, allowing diagnosis of which component is weak.
