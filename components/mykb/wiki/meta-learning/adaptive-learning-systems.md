# Adaptive Learning Systems

## Summary

Adaptive Learning Systems — Systems that tailor content, pacing, and feedback to each learner.

## Details

- Adaptive learning systems adjust the learning experience in real time — which item, how much support, what difficulty — based on a model of the learner. The engine combines knowledge tracing or IRT with decision policies: select the next item that maximizes information or learning gain.
- Evidence: adaptive item selection improves efficiency and outcomes versus fixed sequences in well-measured domains, especially with mastery-based stopping. Benefits shrink when measurement is poor or content is open-ended.
- Worked example: a language app tracks each word's retrieval history; it schedules a word for review when the model predicts it is about to be forgotten, and skips words already consolidated — the schedule is learner-specific, not calendar-specific.
- Design tensions: measurement accuracy versus engagement, model complexity versus transparency, and personalization versus curricular coherence.
- mykb relevance: spaced-repetition-systems are the narrow, proven case; adaptive learning extends the logic to whole curricula.
