# Corrective Feedback Types

## Summary

Corrective Feedback Types — Kinds of error feedback: confirmation, hints, and explanations.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Types range from verification (right/wrong) to elaborated explanations.
- Elaborative feedback generally beats verification for conceptual learning.
- Timing of explanation matters: after self-generation beats before.
- Central design variable for intelligent tutoring systems.
