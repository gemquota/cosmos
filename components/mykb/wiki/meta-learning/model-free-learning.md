# Model-Free Learning

## Summary

Model-Free Learning — Learning stimulus-response values directly from experience without a world model.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Model-free methods cache values from reward history and act reflexively.
- Sample-hungry but fast at execution and resistant to planning costs.
- Maps onto habitual control in humans.
- TD learning and Q-learning are canonical algorithms.
