# Double-Loop Learning

## Summary

Double-Loop Learning — Learning that questions governing assumptions, not just corrects errors.

## Details

- Argyris & Schön distinguish single-loop learning — detecting and correcting errors within existing assumptions — from double-loop learning, which examines and revises the governing variables themselves. A thermostat is the classic single-loop device: it corrects temperature without questioning the setting; a thermostat that asks whether the target is right is double-loop.
- Double-loop learning matters because the most consequential errors are frame errors: optimizing a bad strategy faster does not fix the strategy. It requires surfacing and testing tacit assumptions, which organizations and individuals resist via defensive routines.
- Worked example: a team misses deadlines, so it works longer hours (single-loop); a double-loop response asks whether the estimates, scope, or process itself are wrong — and may change the project's definition of success.
- Enabling conditions: psychological safety, adversarial review, and structured reflection. Learning systems that only accumulate facts are single-loop; systems that revise their categories and goals are double-loop.
- mykb relevance: RSIS3's meta-goal generation is double-loop learning — the agent revises its own improvement targets.
