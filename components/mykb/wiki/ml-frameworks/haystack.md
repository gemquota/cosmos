# Haystack

## Summary
Open-source framework for building production RAG and search pipelines with modular components

## Details
- Composes retrievers, rankers, generators, and readers into typed pipelines.
- Includes evaluation tooling and agent components for complex QA.
- Known for clear interfaces and easy swapping of backends.
- A pragmatic alternative when RAG is the main deliverable.
