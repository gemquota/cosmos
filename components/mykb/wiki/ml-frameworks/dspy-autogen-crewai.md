## Summary
Programmatic and multi-agent frameworks: DSPy optimizes prompts, AutoGen and CrewAI orchestrate agent teams

## Details

- AutoGen provides conversable agents and multi-agent chat patterns from Microsoft.
- CrewAI offers role-based agent crews with simple task delegation.
- Each attacks the same problem — reliable agent behavior — from a different angle.
