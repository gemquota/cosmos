# Model Composition

## Summary
Building systems from multiple models or adapters rather than a single monolithic model

## Details
- Includes routing, cascades, ensembles, and adapter stacking.
- Composition trades complexity for capability and cost control.
- Requires clear contracts between components.
- Underpins routing-models and agent-ensembling.
