# On-Device LLMs

## Summary
Language models that run locally on phones, laptops, or embedded hardware

## Details
- Enabled by quantization, pruning, and small model architectures.
- Works offline and keeps data local.
- Battery, memory, and thermals bound capability.
- A growing target for private assistants.
