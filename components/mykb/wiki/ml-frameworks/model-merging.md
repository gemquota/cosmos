# Model Merging

## Summary
Combining weights from multiple fine-tuned models into one capable model

## Details
- Methods include weight averaging, task arithmetic, and SLERP.
- Merging combines skills without retraining.
- Quality varies by model compatibility.
- Applies to adapters and full checkpoints.
