# OpenAI SDK

## Summary
Official client libraries for calling OpenAI chat, completion, embedding, and assistant APIs

## Details
- Python and TypeScript SDKs wrap REST endpoints with typed helpers and streaming.
- Handle retries, timeouts, and error surfaces consistently.
- The common baseline that many agent frameworks build on.
- SDK upgrades track new models and features such as structured outputs.
