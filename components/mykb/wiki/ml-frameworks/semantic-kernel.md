# Semantic Kernel

## Summary
Microsoft SDK for building AI applications with plugins, planners, and memory across languages

## Details
- Provides plugin (tool) abstractions, prompt templates, and planner components.
- Available for C#, Python, and Java with enterprise focus.
- Emphasizes enterprise integration patterns and responsible defaults.
- Part of the same orchestration landscape as LangChain and Haystack.
