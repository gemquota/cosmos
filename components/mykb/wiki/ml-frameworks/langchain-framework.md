# LangChain Framework

## Summary
Popular framework for composing LLM calls with tools, retrievers, and memory into chains and agents

## Details
- Provides abstractions for prompts, models, retrievers, tools, and memory.
- LangGraph adds graph-based state machines for durable agent workflows.
- Speeds prototyping but its abstractions can obscure control flow.
- A reference point for understanding the broader agent framework space.
