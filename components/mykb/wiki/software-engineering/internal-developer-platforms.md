# Internal Developer Platforms

## Summary
An internal developer platform (IDP) packages infrastructure, CI/CD, environments, and services into self-service golden paths, so developers ship without becoming infrastructure experts. It is DX at organizational scale.

## Details
- Platforms expose paved roads (templates, deploy pipelines) while still allowing escape hatches.
- Measurement focuses on time-to-first-deploy and developer satisfaction, not tool count.
- RSIS3 relevance: cosmos's mykb stack acts as an internal platform for the agent's own knowledge work.
