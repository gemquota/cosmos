# Mob Programming

## Summary
Mob programming (or ensemble programming) has the entire team collaborate on a single task at one machine, rotating the keyboard in short intervals. It maximizes shared understanding and minimizes handoff.

## Details
- Strong for design-heavy work, onboarding, and resolving long-standing disagreements.
- Requires facilitation and breaks; sustained mobbing is exhausting.
- RSIS3 relevance: multi-agent coordination mirrors mob dynamics — one acting, many advising.
