# Bus Factor

## Summary
The bus factor counts how many key people must be hit by a bus before the project stalls. A bus factor of one means a single person holds critical knowledge — the classic knowledge-risk metric.

## Details
- Mitigations: documentation, pairing, code review, and rotating ownership.
- The wiki itself is a bus-factor tool: it externalizes knowledge from any single mind.
- RSIS3 relevance: mykb exists to keep RSIS3's knowledge durable beyond any one session.
