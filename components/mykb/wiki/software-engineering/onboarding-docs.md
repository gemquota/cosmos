# Onboarding Docs

## Summary
Onboarding docs take a newcomer from zero to productive: repository setup, architecture overview, local development, conventions, and a first task. They are the highest-ROI documentation a team writes.

## Details
- Good onboarding docs are verified by every newcomer and updated from their friction.
- The ideal first task exercises the whole loop: checkout, run, test, ship.
- RSIS3 relevance: worker-guide files like this one are onboarding docs for agents.
