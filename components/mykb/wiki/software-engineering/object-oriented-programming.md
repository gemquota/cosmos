# Object-Oriented Programming

## Summary
Object-oriented programming (OOP) models a system as objects — bundles of state and behavior — communicating through messages. Encapsulation, inheritance, and polymorphism are its classic pillars, though modern practice favors composition.

## Details
- Encapsulation hides state behind an interface; polymorphism lets different objects answer the same message differently.
- Composition over inheritance is the dominant modern guideline.
