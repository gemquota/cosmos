# Dialog State Tracking

## Summary
Maintaining structured state of user goals and slots across a conversation

## Details
- Tracks intents, slots, and context across turns.
- Enables multi-turn task completion.
- State errors compound in long conversations.
- Feeds conversation-history-management.
