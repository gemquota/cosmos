# Vision-Language Models

## Summary
Models that jointly process images and text for captioning, QA, and grounding

## Details
- Encode images into the same representation space as text.
- Support OCR, visual QA, and instruction following on images.
- Grounding-vision-to-text links pixels to answers.
- Evaluate with multimodal-evaluation suites.
