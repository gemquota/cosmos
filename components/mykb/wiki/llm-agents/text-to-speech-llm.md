# Text-to-Speech for LLMs

## Summary
Synthesizing natural speech from model text output

## Details
- Modern TTS is neural and expressive with voice cloning options.
- Prosody control improves conversational feel.
- Runs on-device or via API with latency trade-offs.
- Pairs with speech-recognition for voice loops.
