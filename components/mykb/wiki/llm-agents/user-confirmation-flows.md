# User Confirmation Flows

## Summary
Checkpoints where agents must get user approval before consequential actions

## Details
- Confirm destructive, costly, or irreversible actions.
- Present clear summaries of intended effects.
- Confirmation fatigue reduces effectiveness.
- Implemented via permissioning-and-approvals.
