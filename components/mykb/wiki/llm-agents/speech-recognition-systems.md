# Speech Recognition Systems

## Summary
Systems converting audio speech into text with low latency and high accuracy

## Details
- Modern ASR uses end-to-end neural models.
- Handles noise, accents, and code-switching challenges.
- Latency matters for voice-agents.
- Output feeds dialog-state-tracking.
