## Overview

LinearFilter refers to linear filtering, a family of operations that compute each output sample as a weighted sum of neighboring inputs. In graphics, THREE.LinearFilter is the texture-filtering mode that blends the four nearest texels for smooth magnified images; in signal and image processing, linear filters perform smoothing, sharpening, and edge detection via convolution. ## Convolution

A linear filter is defined by a kernel: a small matrix of weights applied across the input. Each output pixel is the sum of input pixels multiplied by the kernel weights, which makes the operation a convolution. Common kernels include the box blur, Gaussian blur, Sobel edge detector, and sharpen kernels. Edge handling, kernel normalization, and boundary conditions determine the quality of the result.

## In Rendering

In graphics APIs, texture filtering selects how texels map to screen pixels: nearest-neighbor sampling picks the closest texel and keeps a blocky look, while linear filtering interpolates between the four nearest texels for smooth results. Mipmapping and anisotropic filtering refine this further at oblique angles. Choosing the right filter balances image quality against bandwidth and cache cost.
