In computing, CTRL (control) refers to the modifier key that, combined with other keys, sends control characters or triggers commands. The terminal interprets these sequences before the application sees them, which is why Ctrl-C interrupts a running process and Ctrl-D signals end of input.

Control characters, such as the ASCII codes 0x00 through 0x1F, predate graphical interfaces and remain important in protocols and shells. Escape sequences, beginning with the ESC character, encode cursor movement, color, and other terminal capabilities. Understanding them matters for building robust CLI tools that render correctly in interactive terminals.

The word control also appears in architecture discussions: control flow determines the order of execution in a program, and the control plane in networking and cloud systems manages configuration and policy, separate from the data plane that carries traffic. In security contexts, access control governs who can perform which actions, and control measures such as rate limiting protect services from abuse.

In agent sessions the term appears alongside API, backend, and security topics, where control shows up as command handling, flow control, and authorization.
