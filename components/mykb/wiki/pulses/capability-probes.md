# Capability Probes

## Summary
Capability probes are minimal, targeted tests for specific skills: a particular reasoning type, a tool-use pattern, a hazardous behavior.

## Details
- Capability probes are minimal, targeted tests for specific skills: a particular reasoning type, a tool-use pattern, a hazardous behavior.
- Probes are cheap to run often and can be inserted into longer pipelines to detect emerging capability early.
- Probe design must resist memorization and contamination.
- RSIS3 relevance: capability tracking in the loop uses probes on the knowledge graph's own outputs.
