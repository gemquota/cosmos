# Recursive Improvement Loops

## Summary
A recursive improvement loop is any cycle in which the system's gains become inputs to the next cycle: better tools make better tools, better knowledge makes better knowledge.

## Details
- A recursive improvement loop is any cycle in which the system's gains become inputs to the next cycle: better tools make better tools, better knowledge makes better knowledge.
- The loop's speed is set by iteration cost and verification cost; cheap, gated iterations compound fastest.
- RSIS3 relevance: the pass system is an explicit recursive loop over the knowledge graph.
- Open questions: how to measure loop health without gaming the metric.
