# Improvement Metrics

## Summary
Improvement metrics quantify progress: benchmark scores, task success rates, graph density, error counts.

## Details
- Improvement metrics quantify progress: benchmark scores, task success rates, graph density, error counts.
- Good metrics are verifiable, stable, and resistant to gaming; each metric needs a defined owner and cadence.
- Metric portfolios beat single metrics because any one can be gamed.
- RSIS3 relevance: pulse scores, check-pass rates, and link health are the bundle's metric portfolio.
