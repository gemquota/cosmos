# Tablet Support

Tablet support means designing for wide screens: multi-pane layouts, side navigation, and content that uses the extra space instead of stretching. It is a product decision, not a device checklist.
- Use window size classes to select pane layouts.
- List-detail is the canonical tablet pattern.
- Avoid phone-shaped full-width lists and huge touch targets.
- Android and iPadOS share the same large-screen discipline.
