# Swift Language

Swift is Apple open-source language: type-safe, protocol-oriented, with value semantics and modern concurrency (async/await, actors). It replaced Objective-C as the primary iOS and macOS language.
- Optionals, generics, and pattern matching keep code safe and terse.
- Swift Concurrency adds structured async work with actors.
- Interops with Objective-C and C; used on servers via Vapor.
- SwiftUI is written entirely in Swift.
