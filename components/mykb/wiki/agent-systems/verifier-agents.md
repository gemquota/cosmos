# Verifier Agents

## Summary
Agents that check outputs for correctness, safety, or compliance

## Details
- Verifiers run tests, check constraints, and validate claims.
- They gate final outputs in generator-verifier-loop patterns.
- Verifier reliability bounds overall quality.
- Distinct from critic-agents in scope.
