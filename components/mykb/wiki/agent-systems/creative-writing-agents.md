# Creative Writing Agents

## Summary
Creative writing agents draft stories, scripts, and marketing copy with explicit control over style, voice, and structure. They matter because creative output is subjective, and agents succeed by turning taste into controllable parameters. The workflow is iterative: draft, critique, revise, until the output matches the brief. Creative agents succeed by treating taste as a controllable parameter.

## Details
- **Definition** — a creative writing agent produces original text for narrative or marketing purposes, guided by style, persona, and audience constraints.
- **Voice control** — persona-prompting and style-adaptation shape voice, while tone-control manages emotional register.
- **Iteration** — multi-draft loops with critic-agents find weaknesses a single pass misses; revision is where quality is built.
- **Briefs** — strong creative output starts with a detailed brief: audience, format, constraints, examples, and hard requirements.
- **Evaluation** — quality is subjective, so human taste and rubric-based judgment matter more than automated metrics.
- **Worked example** — a marketing team asks an agent for three headline variants in a playful tone; a critic flags the third as off-brand, and the agent revises it.
- **Failure modes** — generic prose, cliché density, style drift across drafts, and ignoring format constraints are common failure modes.
- **Multimodal extension** — creative agents extend into multimodal ideas, pairing image-generation-prompts with narrative concepts.
- **Practical relevance** — creative writing agents are a testbed for style control and critique loops that generalize to all content generation.
- **Constraints** — hard requirements like word count, format, and banned phrases should be checked programmatically.
- **Inspiration control** — example passages steer style more reliably than adjectives about style.
- **Draft strategy** — generate multiple directions first, then commit to one for refinement.
- **Failure example** — an agent that ignores the word-count constraint produces copy that cannot ship.
