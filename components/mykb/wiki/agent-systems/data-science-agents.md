# Data Science Agents

## Summary
Agents that explore data, run analyses, and produce reports or models

## Details
- Combine code execution, plotting, and statistical reasoning.
- Handle messy data with iterative cleaning steps.
- Outputs include notebooks, charts, and summaries.
- Depend on safe execution and data governance.
