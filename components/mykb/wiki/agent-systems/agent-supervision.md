# Agent Supervision

## Summary
Human or system oversight of agent activity with intervention authority

## Details
- Ranges from review-before-apply to exception-only monitoring.
- Good supervision scales with risk and autonomy.
- Implemented via permissioning-and-approvals.
- Complements escalation-handling.
