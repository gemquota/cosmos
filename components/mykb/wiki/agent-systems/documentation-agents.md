# Documentation Agents

## Summary
Agents that read codebases and produce or update documentation

## Details
- Generate API docs, READMEs, and architecture notes from code.
- Keep docs in sync via change detection and regeneration.
- Quality depends on code context and style guidelines.
- Examples: markdown-output-rendering consumers.
