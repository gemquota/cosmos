# Agent Pipelines

## Summary
Composing multiple agent stages into a sequential processing pipeline

## Details
- Stages such as plan, retrieve, generate, verify, and report.
- Each stage has inputs, outputs, and error handling.
- Pipelines trade flexibility for predictability.
- Underpin agent-factories and templates.
