# Agent Consensus

## Summary
Mechanisms for multiple agents to agree on decisions or outputs

## Details
- Voting, debate, and quorum rules aggregate agent opinions.
- Consensus improves reliability on high-stakes outputs.
- Cost grows with participant count.
- Distinct from market-based coordination.
