# Critic Agents

## Summary
Agents that review and critique outputs from other agents

## Details
- Critiques find errors, gaps, and improvement opportunities.
- Used in generator-verifier-loop patterns.
- Critic quality bounds the improvement effect.
- Compose with verifier-agents.
