# Simulation Environments for Agents

## Summary
Sandboxed worlds where agents can be tested against realistic scenarios

## Details
- Simulate users, tools, and environment responses.
- Enable agent-evaluations without real-world cost.
- Scenarios cover success and failure paths.
- Foundation of offline-agent-testing.
