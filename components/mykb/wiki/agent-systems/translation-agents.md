# Translation Agents

## Summary
Agents that translate text with context awareness and quality control

## Details
- Handle glossaries, style guides, and domain terminology.
- Quality checks include back-translation and human review.
- Multilingual-prompting complements dedicated translation.
- Benchmarked with BLEU-style and human metrics.
