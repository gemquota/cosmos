# Approval Workflows

## Summary
Approval workflows define which changes need sign-off before they land: structural changes (merges, splits, deletes), policy changes, and keystone article rewrites.

## Details
- The workflow names the approver, the evidence required, and the fallback when approval stalls.
- Approval is a cost — it slows work — so the bar is set where reversibility ends: cheap changes skip approval, expensive ones require it.
- For mykb, approval workflows sit above the review queues and below the editorial policy.
