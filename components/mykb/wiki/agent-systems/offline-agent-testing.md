# Offline Agent Testing

## Summary
Testing agents against recorded or simulated data without live dependencies

## Details
- Replay traces, mock tools, and use golden datasets.
- Deterministic and repeatable versus live testing.
- Catches regressions before deployment.
- Feeds llm-regression-testing.
