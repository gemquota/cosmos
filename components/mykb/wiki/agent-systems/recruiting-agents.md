# Recruiting Agents

## Summary
Agents that screen candidates, schedule interviews, and draft evaluations

## Details
- Match candidates to roles from resumes and profiles.
- Bias-and-fairness-eval is critical for hiring decisions.
- Human review gates final decisions.
- Data privacy rules apply to candidate data.
