# Code Generation Agents

## Summary
Agents that plan, write, test, and iterate on code across whole repositories

## Details
- Go beyond single-file generation to repo-wide edits and test loops.
- Use tools for search, execution, and version control.
- Success measured by passing tests, not just generated text.
- Foundation for code-repair and testing agents.
