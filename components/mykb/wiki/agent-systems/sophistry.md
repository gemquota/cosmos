# Sophistry

## Summary
Sophistry is reasoning that sounds persuasive while being misleading or fallacious.

## Details
- Sophistry is reasoning that sounds persuasive while being misleading or fallacious.
- Models can produce fluent rationalizations for wrong conclusions.
- Sophistry resists factual checks because it tracks plausibility, not truth.
- RSIS3 relevance: generated syntheses must be audited against sources, not fluency.
