# Instruction Following

## Summary
Instruction following is a model's reliability at executing stated instructions, including complex, multi-step ones.

## Details
- Instruction following is a model's reliability at executing stated instructions, including complex, multi-step ones.
- Reliability varies with instruction clarity, format, and conflict.
- Instruction hierarchy and robust prompting improve it.
- RSIS3 relevance: worker briefs are instructions; pass outcomes test adherence.
