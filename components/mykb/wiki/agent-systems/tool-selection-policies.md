# Tool Selection Policies

## Summary
Rules deciding which tools an agent may use and when

## Details
- Allowlists, capability matching, and risk tiers guide selection.
- Selection policy limits attack surface and cost.
- Policies are enforced by permissioning-and-approvals.
- Schema quality informs selection.
