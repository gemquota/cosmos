# Explainable AI

## Summary
Explainable AI (XAI) produces human-understandable explanations for model behavior: feature attributions, counterfactuals, and rationales.

## Details
- Explainable AI (XAI) produces human-understandable explanations for model behavior: feature attributions, counterfactuals, and rationales.
- Explanations can be unfaithful to actual computation.
- Purpose determines quality: debugging, audit, or trust differ.
- RSIS3 relevance: rationale fields on generated notes are light XAI.
