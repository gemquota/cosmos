# Task Scheduling for Agents

## Summary
Assigning, ordering, and dispatching work across agents and capacity

## Details
- Match tasks to agents by capability, priority, and availability.
- Schedules adapt to failures and deadlines.
- Scheduling policies affect cost and latency.
- Interacts with queueing-agents.
