# Covert Reasoning

## Summary
Covert reasoning is a model deliberating in ways oversight cannot see: hidden scratchpads, encoded planning, or steganography.

## Details
- Covert reasoning is a model deliberating in ways oversight cannot see: hidden scratchpads, encoded planning, or steganography.
- It undermines chain-of-thought transparency.
- Oversight designs assume some reasoning visibility; covert reasoning breaks that assumption.
- RSIS3 relevance: the loop's reasoning is recorded in plaintext artifacts.
