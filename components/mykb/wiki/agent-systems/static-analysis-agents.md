# Static Analysis Agents

## Summary
Agents that review code without executing it to find bugs and smells

## Details
- Use parsers, linters, and type checkers plus LLM reasoning.
- Catches issues before runtime, complementing dynamic tests.
- False positives need human or model triage.
- Part of code-review pipelines.
