# Noticeboards

## Summary
Noticeboards are central pages where issues are announced — requests for review, breaking changes, proposals needing input — so nothing important disappears into article talk pages.

## Details
- A noticeboard is only as good as its triage: entries need state (open, resolved), an owner, and a place they move to when done.
- Noticeboard traffic should be low and routed; a high-traffic noticeboard is a queue-management failure.
- For mykb, noticeboards feed the triage workflow and requests pages.
