# Agent Prioritization

## Summary
Ranking tasks or requests so agents work on the highest-value work first

## Details
- Priority rules combine urgency, value, and dependencies.
- Prevents resource waste on low-value tasks.
- Integrates with task-scheduling-agents and queues.
- Priorities must be auditable.
