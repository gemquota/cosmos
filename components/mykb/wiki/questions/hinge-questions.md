# Hinge Questions

## Summary

Hinge Questions — Single checkpoints in a lesson where the class must answer to proceed.
This stub frames the concept for expansion in the Cognition, Learning & Meta-Knowledge cluster.

## Details

- Hinge questions test the concept just taught; ~90% must answer correctly to continue.
- Enable just-in-time reteaching decisions.
- Well-designed hinge questions expose common misconceptions.
- A core move in responsive teaching.
