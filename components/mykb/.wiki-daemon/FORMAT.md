# mykb `.wiki-daemon/` — Canonical Index Format

## Index Files

| File | Format | Produced By | Schema |
|------|--------|-------------|--------|
| `vdb.npz` | compressed numpy | `vectordb.py` | Sparse TF-IDF matrix: rows=documents, columns=vocabulary |
| `vdb_tfidf.json` | JSON | `embedder.py` | `{"vocab": [str], "idf": [float], "doc_ids": [str], "doc_metadata": {str: dict}}` |
| `graph.json` | JSON | `graph_engine.py` | `{"nodes": [{id, label, type}], "edges": [{source, target, weight}]}` |
| `backlinks.json` | JSON | `backlinks.py` | `{target_slug: [{source_slug, context}]}` |
| `timeline.json` | JSON | `temporal_engine.py` | `{entity_slug: [{date, session, session_tags}]}` |
| `config.json` | JSON | `consolidate.py` | `{"wiki_root": str, "last_build": str}` |

## Deprecated (archived in `archive/`)

All files under `archive/indexes/`, `archive/js-search/`, and `archive/legacy/` are
from previous generations of the search infrastructure (JS-based daemon and legacy
Python viewers). They are kept for reference but are not used by any current code.

## Regeneration

All index files are regenerated by `consolidate.py`:
```bash
python3 .wiki-daemon/consolidate.py
```

Or individually:
```bash
python3 .wiki-daemon/embedder.py        # → vdb.npz + vdb_tfidf.json
python3 .wiki-daemon/graph_engine.py    # → graph.json
python3 .wiki-daemon/backlinks.py       # → backlinks.json
python3 .wiki-daemon/temporal_engine.py # → timeline.json
```
