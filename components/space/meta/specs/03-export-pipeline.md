**Status:** Draft

**Created:** 2026-07-25
**Depends On:** `01-data-schema.md`, `02-architecture.md`

---

## 1. Purpose

Defines how completed (or partial) session data is transformed into production-ready specification documents in multiple formats. Fixes the broken `consolidate-spec.sh` and provides a unified export system.

## 2. Scope

- JSON v2 export (structured, machine-readable)
- Markdown specification document (human-readable)
- YAML export (config-style)
- Prompt template export (single system prompt for LLMs)
- HTML/PDF export (styled document)
- Diff/comparison between sessions

## 3. Background / Context

The original framework has two export mechanisms, both broken:
1. Browser-only JSON download in `Summary.jsx` (v1 format, no metadata)
2. `consolidate-spec.sh` with broken JSON concatenation (invalid output)

SPACE replaces both with a programmatic pipeline that produces valid, rich output in 6 formats.

## 4. Design

### 4.1 Pipeline Architecture

```
SessionState + ArtifactDictionary
        │
        ▼
┌───────────────────┐
│  Export Formatter  │ ← format-specific transformer
│  (strategy pattern)│
└────────┬──────────┘
         │
    ┌────┴────┬──────────┬───────────┬──────────┬──────────┐
    ▼         ▼          ▼           ▼          ▼          ▼
  JSON v2   Markdown    YAML      Prompt     HTML/PDF    Diff
    │         │          │          │          │          │
    ▼         ▼          ▼          ▼          ▼          ▼
  .json      .md        .yaml     .txt       .html      .diff
```

### 4.2 JSON v2 Export

Exports the full session state with all answers resolved to human-readable text:

```json
{
  "export_version": "2.0.0",
  "exported_at": "2026-07-25T12:00:00Z",
  "session": {
    "id": "abc-123",
    "project_name": "My Project",
    "completion_pct": 100,
    "total_time_minutes": 52
  },
  "framework": {
    "name": "Structured Prompt Creation Framework",
    "version": "2.0.0"
  },
  "series": [
    {
      "id": 1,
      "name": "Conceptual Depth",
      "rounds": [
        {
          "round": 1,
          "focus": "Domain and Audience",
          "questions": [
            {
              "id": "1.1.1",
              "text": "What is the primary domain...",
              "answer": {
                "open_ended": "Machine learning with focus on NLP...",
                "selected_choice": "An interdisciplinary space spanning 2-3 domains",
                "answered_at": "2026-07-25T12:05:00Z"
              }
            }
          ]
        }
      ]
    }
  ],
  "artifacts": {
    "domain": { "value": "machine learning", "source": "1.1.1", "confidence": 0.9 }
  }
}
```

### 4.3 Markdown Export

Generates a complete specification document with:

```markdown
# Specification: [Project Name]

> Generated by SPACE — Structured Prompt Creation Framework v2.0.0
> Date: 2026-07-25 | Completion: 100% | Time: 52 minutes

## Table of Contents
1. [Conceptual Depth](#1-conceptual-depth)
2. [Ontological Characteristics](#2-ontological-characteristics)
...

---

## 1. Conceptual Depth

### Round 1: Domain and Audience

**Q 1.1.1** — What is the primary domain or field this project addresses?

> **Answer:** Machine learning with focus on NLP...

> **Selection:** An interdisciplinary space spanning 2–3 domains

---

**Q 1.1.2** — Who is the intended audience?

> **Answer:** Practitioners with moderate ML background...

> **Selection:** Practitioners / professionals

...
```

### 4.4 YAML Export

Same structure as JSON v2 but in YAML format for config-style consumption:

```yaml
export_version: "2.0.0"
session:
  id: abc-123
  project_name: My Project
series:
  - id: 1
    name: Conceptual Depth
    rounds:
      - round: 1
        questions:
          - id: "1.1.1"
            answer:
              open_ended: "Machine learning..."
              choice: "An interdisciplinary space spanning 2-3 domains"
```

### 4.5 Prompt Template Export

Combines all answers into a single, copy-paste-ready system prompt:

```
You are a development specification for [Project Name].

## Domain & Audience
Primary domain: Machine learning, interdisciplinary spanning NLP and...
Audience level: Practitioners / professionals

## Entities & Structure
The domain contains the following primary entities:
- Entity A: [from answer 2.1.1]
- Entity B: [from answer 2.1.1]
...

## Relationships
Entities are connected through:
- A → B: [relationship type from 3.1.2]
...

## Technical Requirements
- Hardware: [from 5.1.x]
- Software: [from 5.2.x]
- Performance: [from 5.3.x]

## Development Process
- Methodology: [from 6.1.1]
- Team: [from 6.1.2]
...

## Operations
- Deployment: [from 7.1.1]
...
```

### 4.6 Diff / Comparison

Compares two sessions to identify specification drift:

```markdown
# Specification Diff: Session A → Session B

## Changed Answers
| Question | Series 1 (A) | Session 2 (B) |
|----------|:------------:|:-------------:|
| 1.1.1 | single domain | interdisciplinary |
| 5.2.1 | single language | polyglot |

## New Answers (only in B)
- 7.3.2: Long-term stewardship plan

## Removed Answers (only in A)
- 3.2.1: DAG hierarchy (changed to shallow hierarchy in B)
```

## 5. Interfaces

### 5.1 Exporter Interface

```typescript
interface Exporter {
  format: ExportFormat;
  
  export(session: SessionState, artifacts: ArtifactDictionary, opts?: ExportOptions): ExportResult;
  
  validate?(session: SessionState): ValidationResult;
}

type ExportFormat = 'json' | 'markdown' | 'yaml' | 'prompt' | 'html' | 'diff';

interface ExportResult {
  content: string;
  filename: string;
  mime_type: string;
  size_bytes: number;
}

interface ExportOptions {
  include_metadata?: boolean;      // default: true
  include_empty_answers?: boolean; // default: false
  include_artifacts?: boolean;     // default: true
  project_name?: string;           // override project name in output
  template_style?: 'full' | 'compact'; // for prompt export
  diff_against?: SessionState;     // for diff export
}
```

### 5.2 Pipeline Entry Point

```typescript
function exportSession(
  session_id: string,
  format: ExportFormat,
  options?: ExportOptions
): Promise<ExportResult>;

function exportToFiles(
  session_id: string,
  output_dir: string,
  formats: ExportFormat[]
): Promise<string[]>;  // returns file paths
```

## 7. Edge Cases

- **Partial session export:** Supported — only answered questions included
- **Empty open-ended answer:** Included with placeholder `[Not answered]` if `include_empty_answers` is true
- **No multi-choice selected:** Included as `[No selection]`
- **Missing artifacts:** Referenced artifacts in templates resolve to `[Not yet determined]`
- **Very long answers:** Markdown export uses `<details>` collapsible for answers >500 chars

---

## 8. Testing Strategy

- Round-trip: JSON v2 export → import → re-export produces identical output
- Markdown export renders valid Markdown (markdownlint)
- Prompt template export produces valid, copy-paste-ready text
- Diff produces correct additions/removals/modifications
- All exporters handle empty/partial sessions without errors
